# 内容组织与文章搜索

## 栏目与目录

顶部导航保留生活、奶茶仙人、办公、电影人生与关于，首页通过 Logo 返回。文章目录入口保留在首页与搜索弹窗；电影人生已发布首篇影评并恢复顶部入口。生活页自动展示分类卡片、简介与公开文章篇数，栏目页正文不再维护重复文章清单。`/articles/` 采用简洁标题、搜索区、文章卡片与右侧层级目录；手机上目录移到文章列表上方。栏目与主题只保留一套筛选入口，选中栏目后展开对应主题或品牌。生活可按主题、饮品可按品牌筛选；无 JavaScript 时仍能浏览全部文章。

现有 Page Bundle 路径与 URL 保留。本轮调整的是读者可见的入口与主题名称，未批量移动文章。

栏目目录先在星巴克品牌页与拿铁草稿页试点（`showSectionTree: true`）：宽屏左侧固定目录，窄屏通过“浏览栏目”打开抽屉；只展开当前品牌，公开目录不列草稿。当前草稿仅在自身预览页标注显示，发布状态不变。面包屑展示首页、上级与当前页。

## 搜索实现

Hugo 构建时通过 `layouts/_default/index.json` 生成 `index.json`，浏览器首次输入关键词时下载并缓存。项目级 `assets/js/search.js` 覆盖主题搜索脚本，保留主题入口；Fuse.js 作为无直接结果时的英文拼写容错。无需搜索服务器，也不使用 Pagefind。

全站搜索通过 `search-pages.html` 收录未排除搜索的公开文章与独立页面；“关于”保留在搜索中。文章目录在此基础上仅展示生活、办公、饮品和电影栏目文章，不收录“关于”。分类、标签、栏目聚合页和草稿不参与文章结果；`hugo server -D` 预览中的草稿也不会进入本搜索索引。

搜索字段包括标题、完整栏目路径、标签/分类、别称、摘要与正文：

- 多个空格分隔的词可以命中不同字段，例如“瑞幸 拿铁”“南京 大学”。所有词都需要匹配。
- 标题匹配优先于标签、栏目、摘要与正文中的提及；结果显示完整栏目路径，方便区分同名饮品。
- 统一大小写、全角字符和空格。支持 `Intl.Segmenter` 的浏览器会补充中文连写分词。
- 直接匹配无结果时，对拉丁文字使用保守的 Fuse.js 容错；不是语义搜索，不能保证理解任意自然语言或未登记的别称。
- 弹窗支持 `/` 与 `⌘K` / `Ctrl K` 快捷键、栏目筛选，最多展示前 60 条并提示总数；目录页可继续按主题/品牌缩小范围，每次展示 12 篇，可点击继续翻阅。
- 加载完成后处理当前查询，中文输入法候选阶段不提前搜索；加载失败有重试按钮。

## 维护别称

标题不必为了搜索堆词。少量站点级别称可在 `data/search.toml` 登记；文章自己的补充词可写入 front matter：

```yaml
searchKeywords: [雷鸟, 邮箱管理]
```

主动排除示例页等内容可设置：

```yaml
excludeFromSearch: true
```

`draft: true` 的文章不属于公开索引。找不到新稿时先确认是否已经发布，再检查标题、栏目与关键词，不通过公开草稿来解决搜索问题。

## 验证

```bash
node --test scripts/test-search.cjs
bin/hugo --minify --gc --environment production
SEARCH_INDEX=public/index.json node --test scripts/test-search.cjs
```

第一条检查排序、多词、别称、英文容错与加载重试；第三条核对实际构建索引的代表性文章与草稿排除。CI 在构建镜像前运行搜索逻辑测试。

目录页标题采用 H1 → 结果区 H2 → 文章卡片 H3，卡片标题仅在本目录模板中调整。目录页通过 `article-link/card.html` 复用 Blowfish 原生卡片，有明确封面的文章沿用封面，其他文章用栏目图标封面，避免把通用风景图误当成饮品或景点实拍。样式沿用主题配色并适配深色模式。未整体更换主题或修改文章地址。

搜索改动使用项目覆盖文件，不直接编辑 `themes/blowfish/`。主题升级时核对搜索按钮 ID、入口模板和主脚本加载方式，保留键盘和移动端检查。
