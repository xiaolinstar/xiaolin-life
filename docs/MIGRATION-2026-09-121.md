# 迁移记录：124.222.98.227 → 阿里云 121（备案审计整改）

> 日期：2026-09-19
> 类型：基础设施迁移（备案合规）

## 动机

阿里云备案系统登记的接入服务器为 121.x.x.x（阿里云 ECS），但站点实际部署在 124.222.98.227（腾讯云）。审计指出两者不一致，违反工信部「备案接入信息须与实际一致」规定。

## 新架构

```text
DNS xiaolin.fun → 121 公网入口（合一）
  └─ 121 上跑 xiaolin-life 容器
       ├─ 80 端口（HTTP）→ 301 重定向到 443
       ├─ 443 端口（HTTPS，SSL 终结在容器内 nginx）
       └─ 容器内 8080（仅回环，含 healthcheck）
```

旧链路（已废弃）：

```text
DNS xiaolin.fun → 101（公网 + xiaolin-gateway + SSL）→ 反代 → 124:8081（xiaolin-life 容器）
```

## 关键决策

| 维度 | 决策 |
|---|---|
| SSL 终结点 | 121 容器内 nginx |
| 证书方案 | **复用 101 上的腾讯云免费证书**（scp 到 121，文件名 `xiaolin.fun_bundle.crt` + `xiaolin.fun.key` 与 xiaolin-gateway 约定一致） |
| 监听端口 | 容器内 80 + 443，宿主映射 `80:80` + `443:443` |
| SSH 认证 | 继续密码（未切换到 SSH Key / Deploy Key） |
| 124 保留 | DNS 切后保留 30 分钟观察窗口再清理 |
| 101 网关 | 停止（外部 xiaolin-gateway 仓库操作） |
| stub_status | 改为 `127.0.0.1:8081`，仅容器内可访问 |
| 镜像源 | 暂保持 `ghcr.nju.edu.cn/xiaolinstar/xiaolin-life:main` |

- git revert 当前 commit，重新 `docker compose up`
