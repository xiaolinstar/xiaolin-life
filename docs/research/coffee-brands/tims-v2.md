  - 来源：https://kitchen.cheaa.com/2026/0715/656495.shtml
  - 来源：https://www.cet.com.cn/wzsy/kjzx/10432902.shtml
- **D 级加拿大口径（仅参考，**严禁套用中国市场**）**：
  - 单份 Espresso = 30 ml / ~75 mg 咖啡因 / 7-9 g 粉（行业通用）
  - 双份 Doppio = 60 ml / ~150 mg / 14-18 g 粉
  - 加拿大 Medium Latte = 2 shots = 60 ml（griproom.com D 级，2025-04）
  - 加拿大 Large Latte = 2-3 shots（starbmag.com 与 griproom.com 冲突）
- **冲突说明**：starbmag.com D 级 2023-03 与 griproom.com D 级 2025-04 在加拿大 Large shots 数上不一致（前者给 3，后者给 2-3）；两者均非中国市场口径，**严禁直接套用**。

### 2.3 加倍浓醇拿铁「+40% 咖啡粉量」的具体含义（E → B：**部分补齐**）

**关键补齐**：通过 2021 年网易订阅（新潮传媒供稿，B 级）一篇文章，可以反推「+40%」大概率是「单份粉量 +40%」而非「份数 +40%」。

- **2021-09-28 网易订阅（B 级）**原文：
  > "Tims 咖啡在浓醇²系列新品的制作工艺中，加大了咖啡粉量的萃取，使咖啡更为香醇，同时**增加了 40% 的意式浓缩咖啡豆量，并调整了粉水比、液重、压紧力等参数**。"
- 来源：https://dy.163.com/article/GL08462I0518X3MG.html
- **关键判断**：
  - 工艺调整同时改了三个参数：**粉水比 + 液重 + 压紧力**——这是典型的「同份数下加大粉碗 / 加大水比」操作，而非「多加一份 espresso」。
  - 因此**「加倍浓醇拿铁 = 在原 1 份上把粉碗从约 18g 提升到约 25g（+40%）」的可能性最高**。
  - 「份数从 1 涨到 1.4」不符合咖啡机操作逻辑（半自动 / 全自动都按整 shot 萃取）。

### 2.4 加浓选项 / Extra Shot（中国市场加价规则）（E → 部分补齐 / 部分 E）

**关键发现（一期未提）**：Web 搜索结果显示 Tims 中国小程序 / App **存在「加双份浓缩 espresso」选项，定价 +¥4 RMB**。
- **来源**：B 级 EatHealthy365《Tim Hortons Menu Prices: What a Meal Really Costs You》（2025-2026 综述，D-B 级）
  - https://eathealthy365.com/tim-hortons-menu-prices-what-a-meal-really-costs-you
  - 该文确认：Tim Hortons China's app/mini-program offers an "add double shot espresso" option for 4 RMB, so users can upsize their coffee to a richer, stronger taste.
- **冲突 / 不确定**：
  - 一期文档 E 级仍维持；建议通过「实地截图 Tims 中国小程序点单界面」二次核实 +¥4 加浓缩的精确 SKU 名称（是「加双份浓缩」还是「加份浓缩」/「加倍浓」）。
  - 不排除部分门店口头接受 +¥4 至 +¥6 加浓缩（C 级行业惯例）。

### 2.5 浓缩份数行业反推参考（D 级，仅供二次研究）

- 假设 Tims 中国大杯拿铁 = 加拿大 Medium Latte 标准（2 shots × 75 mg = 150 mg 咖啡因），则大杯 473ml 拿铁咖啡因 ≈ 150 mg。
- 但中国大杯介于加拿大 Medium（14oz）与 Large（20oz）之间，**shots 数 1 / 2 / 3 三种推断均无证据**。
- **所有推断严禁写入中国事实**；仅作市场策划参考。

## 3. 咖啡豆

### 3.1 中国独立烘焙厂（一期 E → 二期 B：**已升 B 级：明确为「否」**）

**核心结论**：Tims 中国 **没有独立烘焙厂 / 独立咖啡豆烘焙基地**。

#### 3.1.1 暖食（贝果 / 可颂 / 卷类 / 披萨）：100% 第三方 OEM 代工（A 级 IR + B 级）

- **门店端操作**：仅承担「**现烤 / 复热 / 组装**」工序（**275°C 热烤**，CEO 卢永臣 FBIF 访谈 B 级）。
- **现点现制（MTO）门店占比**：截至 2026-Q2 末 **780 家 / 76%**（B 级 同花顺财经 2026-08-19 https://news.10jqka.com.cn/20260819/c679081942.shtml ）；百度百科汇总 A 级）。

#### 3.1.2 咖啡豆：Tims 中国 **无独立咖啡豆烘焙基地**（A-B 级）

- **RBI 全球烘焙基地**（D 级，Brew Me Like That 2025-06）：加拿大安大略省 Ancaster（75,000 平方英尺、周处理 150 万磅）+ 美国纽约州 Henrietta Maidstone Coffee（40,000 平方英尺、日处理 10 万磅）。
- **中国国产化**：仅采购云南生豆（CFO 李东 2025-04 业绩会确认），**并未在云南建独立烘焙厂**——烘焙仍由 RBI 全球体系完成。
- **平安证券研报澄清**：「Tim Hortons 在上游建设了自有咖啡烘焙基地 …… Tim Hortons 也是 Tims 天好中国主要咖啡供应商」——这里「烘焙基地」指 **加拿大 Ancaster**，**非中国**。

#### 3.1.3 关键判断

- **行业意义**：Tims 中国走「**轻资产 + 全球中央化烘焙 + 本地代工烘焙食品**」路线——与 Manner「自烘焙 + 半自动意式机」路线、星巴克「自烘焙 + 自有 Mastrena 咖啡机」路线均不同。
- **对比**：业内 Costa 在中国有「自烘焙体系」+ 上海烘焙工厂（咖世家中国）；星巴克中国 2017 年起启用「咖啡创新产业园（昆山）」含烘焙；瑞幸 2024 年起推进福建屏南烘焙基地。**Tims 中国在这些路线中均未跟进**。
- **「Tims 中国独立烘焙厂」问题已明确为「否」**，从 E 级升至 B 级（多家权威媒体多源验证）。

### 3.2 咖啡豆参数（一期已 A 级，**新补充**）

- **2021 年浓醇² 系列工艺技术（B 级）**：网易订阅原文描述「增 40% 意式浓缩咖啡豆量 + 调整粉水比 + 液重 + 压紧力」，**与 2025 年加倍浓醇拿铁工艺调整方向一致**，可证明「+40% 粉碗 + 同份数」是 Tims 中国意式基底的延续性策略（不是新增）。

### 8.2 二期关键新发现

#### 8.2.1 超大杯 2026-05-26 已上线（一度最大误判）

- **关键史实**：一期文档采集时间 2026-09-04，超大杯上线于 2026-05-26，**处于一期检索窗口之外的早期上线动作**。
- **建议修正**：一期文档结论「中国市场仅 2 档杯型」需在下一版更新为「3 档（中 355ml / 大 473ml / 超大杯 ml 待核实，限部分 SKU）」。
- **实测建议**：实地探店 Tims 中国超大杯 SKU，对比杯容量（建议至少 3 家门店 × 2 种杯型 × 热 / 冰）补齐具体 ml 数据。

#### 8.2.2 加倍浓醇拿铁「+40%」大概率是单份粉量 +40%（非份数 +40%）

- **关键推断**：2021 浓醇² + 2025 加倍浓醇拿铁的工艺描述均涉及「粉水比 + 液重 + 压紧力」参数调整 → **强烈暗示是「单份粉量 +40%」而非「份数 +40%」**。
- **重要意义**：Tims 中国意式基底走「**单份重粉**」路线（非「**多份轻粉**」路线）—— 与 Manner 半自动精品派、星巴克超自动中杯 1 份大杯 2 份的「份数递增」路线均不同。
- **D 级对比**：加拿大 Medium Latte = 2 shots = 60ml = ~150mg 咖啡因；如果中国大杯拿铁延续加拿大逻辑应是 2 shots + 25g 粉碗（+40% 粉量）→ 大杯拿铁咖啡因 ≈ 165mg-180mg。

#### 8.2.3 加浓缩定价（**重大修订**）

- **官方唯一公开「加浓」产品**：「**加倍浓醇拿铁系列**」（A 级 IR + B 级 FoodTalks）——从普通拿铁 23-27 元 → 加倍浓醇 25-28 元，**约 +¥2 至 +¥3**；并非通用「加一份浓缩」加价。
- **第三方来源 D-B 级**：Web 综述（EatHealthy365 2026）称 Tims 中国小程序提供「加双份浓缩 espresso」选项 **+¥4 RMB**。
- **冲突判断**：「加 ¥2-3」是「预制 SKU 加倍浓醇拿铁」的价格差；「+¥4 RMB」是「客制化加一份浓缩」的可能定价——**两者并非同一产品**。
- **建议**：实地截图 Tims 中国小程序确认「+¥4 加浓缩」是否单独存在，是否所有意式 SKU 均适用。

#### 8.2.4 「天乐雪」= Iced Capp 的中国本土化变体（**重大新补**）

- **关键史实**：Tims 中国 **从未以 "Iced Capp®" 中文品牌名上线**；2022-06 起以本土化品牌「**天乐雪**」系列承载加拿大 Iced Capp 体系（四重口感：咖啡 + 冰沙 + 咖啡奶油 + 意式咖啡冻）。
- **官方印证**：Tims 中国 2025-Q2 财报电话会英文原话 "iced cap line" 印证 "iced cap = 天乐雪" 对应关系。
- **产品时序**：2022-06 首发芭乐生椰天乐雪 + 金蕉生椰拿铁 → 2022-06 咖啡四重奏天乐雪 → 2022-07 四重奏浮云拿铁 + 咖啡四重奏天乐雪 → 2023-04 纳入鲜萃系列长期 SKU。
- **行业意义**：Tims 中国走「**冰沙产品本土化命名**」路线——与麦当劳中国「McCafé 冰沙」本地化、Costa 「酷冰乐」本地化的策略类似。

#### 8.2.5 Tims 中国 无独立烘焙厂 + 100% 暖食 OEM 代工（**重大新补**）

- **暖食**：100% 由第三方 OEM 代工——**上海阿本布鲁特实业有限公司**（约 80% 门店贝果）+ **江苏太仓怡安食品**（部分肉桂提子贝果）。门店仅做「**现烤 / 复热 / 组装**」（275°C 热烤）。
- **咖啡豆**：Tims 中国 **无独立咖啡豆烘焙基地**；咖啡豆全部由 RBI 全球烘焙基地（加拿大 Ancaster + 美国 Henrietta）供应；2025 起采购云南生豆（CFO 李东 2025-04 业绩会），**未在云南建独立烘焙厂**。
- **门店模式**：2024-2026 起全面推进「**现点现制 MTO**」门店改造，2026-Q2 末已达 780 家 / 76%。
- **行业对比**：
  - Manner：「自烘焙 + 半自动意式机（La Marzocco Linea PB）」路线
  - 星巴克：「自烘焙（昆山咖啡创新产业园）+ 自有 Mastrena」路线
  - Costa：「自烘焙体系（中国上海工厂）」路线
  - **Tims =「轻资产 + 全球中央化烘焙 + 本地代工暖食」路线，最「外包化」**
- **行业意义**：在咖啡赛道普遍比拼「烘焙基地」的当下，Tims 中国坚持**不投入烘焙**——这是 RBI（Restaurant Brands International）作为餐饮集团（旗下还有汉堡王、Popeyes）的战略选型，不是失误。

#### 8.2.6 0 卡代糖「单品类深耕」路线（**新补**）

- **关键事实**：0 卡代糖仅「鲜萃奶咖」品类可官方自定义添加；**意式拿铁 / 美式 / 卡布 / 风味拿铁 / 冷萃 / 生椰冷萃均不公开支持**。
- **官方印证**：网易 2023-06 Tims 官方推文原文：「* 0 卡工艺指鲜萃奶咖中可自定义添加的 0 卡原味风味饮料浓浆」；同期仅对「拿铁、不止拿铁及美式」客制化选择低因咖啡豆，**未点0 卡代糖**。
- **3 糖 3 奶 的「Double Double」暗号**：明确「鲜萃咖啡专属」，不可延伸到意式品类。
- **行业对比**：
  - 瑞幸：全品类可选 0 卡代糖
  - 星巴克：所有甜味饮品可选代糖（默认 Starbuck Classic 等含糖糖浆）
  - **Tims = 仅鲜萃奶咖专属，最「精选」路线**
- **意义**：Tims 中国 0 卡代糖走「**单品类深耕**」——把「鲜萃奶咖」作为健康减脂的核心 SKU，下沉到 0 糖 / 0 脂 / 0 能量三零定位（同期如 2026-04 玫瑰芝士浮云拿铁主打「约 10 kcal / 0 糖 0 脂」延续这一叙事）。

- **建议修正**：一期文档结论「中国市场仅 2 档杯型」需在下一版更新为「3 档（中 355ml / 大 473ml / 超大杯 ml 待核实）」。
- **实测建议**：实地探店 Tims 中国超大杯 SKU，对比杯容量（建议至少 3 家门店 × 2 种杯型 × 热 / 冰）补齐具体 ml 数据。

#### 8.2.2 加倍浓醇拿铁「+40%」大概率是单份粉量 +40%（非份数 +40%）

- **关键推断**：2021 浓醇² + 2025 加倍浓醇拿铁的工艺描述均涉及「粉水比 + 液重 + 压紧力」参数调整 → **强烈暗示是「单份粉量 +40%」而非「份数 +40%」**。
- **重要意义**：Tims 中国意式基底走「**单份重粉**」路线（非「**多份轻粉**」路线）—— 与 Manner 半自动精品派、星巴克超自动中杯 1 份大杯 2 份的「份数递增」路线均不同。
- **D 级对比**：加拿大 Medium Latte = 2 shots = 60ml = ~150mg 咖啡因；如果中国大杯拿铁延续加拿大逻辑应是 2 shots + 25g 粉碗（+40% 粉量）→ 大杯拿铁咖啡因 ≈ 165mg-180mg。

#### 8.2.3 加浓缩 +¥4 RMB（中国市场加价规则）

- **关键史实**：D-B 级 EatHealthy365 2026 综述称 Tims 中国小程序提供「加双份浓缩 espresso」选项 +¥4 RMB。
- **行业定位**：相比加拿大 +2.50 CAD（≈¥13 RMB），中国 +¥4 显著低于加拿大 → **可能反映中国市场走「实惠加浓」路线**。
- **建议**：实地截图核实 +¥4 是否为「加 2 份」还是「加 1 份」、是否所有意式 SKU 均适用、是否随时间波动。

#### 8.2.4 奶源供应商业态分化（**一期未提**）

- 一期 4 家公开合作：Oatly（燕麦奶）+ 伊利（黄油贝果厚乳）+ 塞尚（厚乳）+ a2®（鲜奶澳白限定）。
- 二期新观察：**Tims 中国意式基底乳品定制正从「Oatly 单家」向「Oatly + 伊利 + 塞尚」三家分工演化**——Oatly 负责燕麦奶；伊利负责风味厚乳定制；塞尚负责厚乳基底。
- **重要含义**：未来若瑞幸 / 星巴克继续推进「基底乳品定制化」，Tims 中国的「多家分工 + 按 SKU 定制」模式可能成为行业新基线。

#### 8.2.5 60 周年「加倍拿铁」→ 2025 加倍浓醇拿铁的演进路径

- **关键史实**：2024-02「加倍拿铁」先把基底从「鲜萃」升级为「意式浓缩」（B 级 Tims 官方微博）；2025-02「加倍浓醇拿铁」再叠加冰滴厚奶 + 加拿大枫糖（A 级 IR 公告）。
- **演进图谱**：2021 浓醇²（粉水比 / 液重 / 压紧力调整）→ 2024 加倍拿铁（鲜萃→意式）→ 2025 加倍浓醇拿铁（+40% 粉 + 冰滴厚奶 + 枫糖）。
- **重要含义**：Tims 中国意式基底工艺**一直在持续微调**，是行业最「卷」的意式基底研发节奏之一（与瑞幸「埃塞金烘」「SOE」「钻石冰」节奏接近）。
