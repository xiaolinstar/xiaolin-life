## 1. 杯型容量（中国市场）

星巴克中国市场杯型沿用「中杯 / 大杯 / 超大杯」三段命名（与中文语境习惯一致，无「小杯」），与全球体系对应如下：

| 杯型 | 英文 | 容量（中国门店） | 备注 |
| :--- | :--- | :--- | :--- |
| 短杯 | Short | 约 236 ml（8 oz） | 中国门店**通常不作为常规选项**提供，需向咖啡师特别要求，且多仅供热饮 |
| 中杯 | Tall | **355 ml**（12 oz） | 默认点单起杯；与中国习惯「中杯 = 适中」对齐 |
| 大杯 | Grande | **473 ml**（16 oz） | 加价换杯；浓缩份数从 1 升到 2 |
| 超大杯 | Venti | **591 ml**（20 oz，热饮） | 冰饮因含冰容量更大（约 710 ml / 24 oz） |

**关键事实**：
- 中国星巴克没有 Trenta（916 ml / 30 oz），该规格仅限美国 / 加拿大冰饮。
- 「中杯起步」这一命名在 2016 年曾因消费者讨论引发官方解释，目前维持原状。

## 2. Espresso 浓缩份数（重点核查项）

### 2.1 单份 Espresso 液量基准

| 项目 | 参数 |
| :--- | :--- |
| 单份浓缩（Solo） | 约 **30 ml**（1 fl oz） |
| 双份浓缩（Doppio） | 约 60 ml（2 fl oz） |
| 三份 / 四份 | 90 ml / 120 ml |
| 单份咖啡因 | 约 75 mg（深烘 Signature Roast） |
| Blonde 浅烘单份 | 约 85 mg |

### 2.2 各杯型默认浓缩份数（拿铁、美式、卡布基线）

| 杯型 | 容量 | 拿铁 Latte | 美式 Americano | 卡布奇诺 Cappuccino |
| :--- | :--- | :--- | :--- | :--- |
| 中杯 Tall | 355 ml | **1 份** | **1 份**（+ 热水补足容量） | **1 份** |
| 大杯 Grande | 473 ml | **2 份** | **2 份** | **2 份** |
| 超大杯 Venti（热） | 591 ml | **2 份** | **2 份** | **2 份** |
| 超大杯 Venti（冰） | 约 710 ml | **3 份** | **3 份** | — |

### 2.3 重点核查项结论（用户预判 vs 实际）

用户预判：**「大杯 Grande 和超大杯 Venti 都是 2 份浓缩」**。

**核实结论**：
- **大杯（Grande 473 ml）默认 2 份浓缩** —— 与用户预判一致。
- **超大杯 Venti 默认 2 份** **仅适用于热饮**（拿铁、美式、卡布）。
- **冰 Venti 拿铁 / 美式默认 3 份浓缩**（行业通用做法：因冰块占据容量并稀释咖啡味，需多加一份以平衡浓度）。
- 焦糖玛奇朵（Caramel Macchiato）继承拿铁基线，大杯 2 份、冰 Venti 3 份。

**信息来源**：
- 星巴克中国菜单结构沿用全球默认配方（拿铁 Shot 数 1/2/2 hot、3 iced），与 `starbucks.com.cn` 公开配方逻辑一致。
- 第三方咖啡师指南、知乎 / 咖啡博客交叉验证（详见第 7 节）。

### 2.4 自定义加浓缩

| 操作 | 备注 |
| :--- | :--- |
| 多加 1 份浓缩 | 约 **+4 元**（部分门店 7~10 元） |
| 免费替换豆底 | 默认 Signature 深烘 → 可指定 Blonde Roast（金烘） |
| 去咖啡因 | 可换 Decaf Espresso Roast（无额外费用或极低加价） |

## 3. 咖啡豆

### 3.1 Espresso Roast（浓缩烘焙）—— 经典意式基线

- **名称**：Starbucks® Espresso Roast（中文常译「浓缩烘焙」或直接保留 Espresso Roast）
- **烘焙度**：**深烘焙（Dark Roast）**
- **拼配产地**：**拉丁美洲（拉美）+ 亚太地区** 阿拉比卡豆
  - 巴西：提供巧克力、坚果调与厚实醇度
  - 印度尼西亚（多见苏门答腊）：提供草本、土香调与厚重感
- **咖啡豆种**：100% 阿拉比卡（Arabica）
- **风味**：焦糖甜、深可可、低酸、平衡顺滑
- **专利 / 自有**：星巴克自有拼配（具体百分比未公开）；与全球门店一致。
- **典型用途**：浓缩咖啡、拿铁、美式、卡布奇诺、玛奇朵等所有意式基底饮品。
- **包装规格（中国门店常见）**：250 g、1 kg（门店用大包装）。
- **备注**：在中国菜单中通常不单独以「Espresso Roast」零售咖啡豆形态出现，**更多是门店现磨使用**；星巴克中国「咖啡豆 / 浓缩咖啡豆」产品分类下「意式浓缩烘焙咖啡豆」即对应此 SKU。

### 3.2 Pike Place® Roast（派克市场烘焙）—— 滴滤常驻

- **名称**：Starbucks® Pike Place® Roast
- **烘焙度**：**中度烘焙（Medium Roast）**
- **拼配产地**：**拉丁美洲** 阿拉比卡豆（墨西哥、哥伦比亚、哥斯达黎加、波多黎各等为主）
- **豆种**：100% 阿拉比卡
- **加工法**：水洗（Washed）
- **风味**：可可 + 烤坚果（cocoa & toasted nut），顺滑、平衡
- **酸度**：中等
- **上市年份**：**2008 年**推出，为星巴克咖啡大师调配，命名自西雅图第一家门店所在地的派克市场（Pike Place Market）。
- **专利 / 自有**：星巴克自有标志性拼配。
- **中国市场零售**：星巴克中国官网 `starbucks.com.cn` 有售，200 g 装，经典绿色包装。
- **第三方备注（非官方）**：有测评提及该拼配可能含印尼苏门答腊（约 25~30%）甚至少量越南罗布斯塔（≤5%）—— **此为第三方推测，星巴克官方未确认具体百分比**。

### 3.3 Blonde Roast（金烘浓缩 / 金烘焙）

- **名称**：Blonde Espresso / Blonde Roast
- **烘焙度**：**浅烘焙（Light Roast）**
- **拼配产地**：拉美 + 东非
- **风味**：柑橘明亮、酸度活泼
- **使用场景**：可免费替换深烘 Espresso Roast 作为拿铁 / 美式豆底。

## 4. 奶源供应商

### 4.1 默认牛奶（全国主线）

| 项目 | 信息 |
| :--- | :--- |
| **默认牛奶类型** | 巴氏鲜奶（门店冷链直送，全脂为主） |
| **2007 年起指定供应商** | **蒙牛**（中国蒙牛乳业有限公司） |
| **历史沿革** | 2006 年 11 月星巴克中国公开宣布蒙牛为大陆门店指定乳制品供应商，2007 年起正式覆盖全国（鲜奶品类） |

> **关于用户提问的恒天然 / 现代牧业**：
> - 经搜索**未发现恒天然（Fonterra）或现代牧业作为星巴克中国牛奶直接供应商的官方公告或权威媒体报道**。
> - 现代牧业是中国最大的乳牛畜牧及原奶生产商之一，恒天然是新西兰大型乳企，但**二者均未出现在星巴克中国官方供应商披露信息中**。
> - 标 **「不公开 / 待核实」**，以防误传。

### 4.2 区域供应商（鲜奶 / 低温奶）

星巴克中国**采用本地化采购策略**，不同区域使用不同品牌鲜奶：

| 区域 / 门店 | 区域供应商 | 备注 |
| :--- | :--- | :--- |
| 南京 / 江浙沪 | **卫岗乳业** | 2003 年起合作；CCTV 等媒体报道已为星巴克供应 14 年以上（2017 年口径） |
| 上海 / 成都等 | **光明乳业** | 区域供应商之一 |
| 北区 / 广州部分 | **发喜**（八喜旗下） | 区域供应 |
| 西南 / 重庆部分 | **安佳**（Anchor） | 区域供应 |
| 其他区域 | 雀巢咖啡专用奶 / 澳亚牧场 / 明治 等 | 历史或局部使用 |

> 以上为公开报道与行业资料梳理，**非星巴克中国官方统一披露口径**，各区域门店实际使用品牌以门店为准。

### 4.3 高蛋白拿铁 PRO（2026 合作）

- **2026 年 5 月起**：21 世纪经济报道独家披露 **蒙牛成为星巴克「高蛋白拿铁 PRO」系列的乳业合作方**，采用「6.0 高蛋白 0 乳糖牛乳」（每 100 ml 含 6 g 原生乳蛋白）+ 蒙牛 **EHT 酶水解专利技术**。
- 一杯大杯「高蛋白拿铁 PRO」蛋白质约 20 g，约相当于 3 个鸡蛋。
- 双方合作有保密要求，**蒙牛与星巴克均未正式官方公告产品合作细节**。

### 4.4 燕麦奶（OATLY）—— 独家

- **合作关系**：**独家品牌合作（exclusive branded partnership）**
- **合同覆盖**：截至 2020 年 12 月 31 日，中国 4700+ 星巴克门店**独家使用** OATLY 燕麦奶（来源 OATLY 招股说明书）
- **中国运营主体**：欧力（上海）饮料有限公司（OATLY 中国）
- **上线时间**：2020 年 4 月 22 日起在星巴克中国内地所有门店推出燕麦拿铁等系列
- **使用方式**：顾客可免费将任意星巴克饮品**更换为燕麦奶**调制（无加价）

### 4.5 其他奶选项

- **全脂奶**（默认）
- **脱脂奶**
- **豆奶**（豆奶供应商未单独披露）
- **椰奶 / 杏仁奶**（可选范围有限，多数门店以燕麦奶为主推植物奶）

## 5. 默认温度

| 品类 | 默认形态 | 温度区间 |
| :--- | :--- | :--- |
| 热拿铁 / 热美式 / 热卡布 | 热饮 | 约 **60~65°C**（介于烫口与适口之间） |
| 冰拿铁 / 冰美式 | 冰饮（默认加冰至约半杯） | 约 **4~6°C** |
| 浓缩咖啡（单品） | 热饮 | 约 **65~70°C**（浓缩液萃取温度约 92~96°C，加水后降温） |
| 焦糖玛奇朵 | 热 / 冰可选 | 与拿铁一致 |
| 馥芮白 Flat White | 仅热饮（标准做法） | 约 **60~65°C** |

**定制范围**：
- 热饮可向咖啡师要求温度调整（区间约 50~80°C）。
- 冰饮可选「少冰 / 去冰」。
- **官方未公开标定温度数值**；上述温度区间来自咖啡师经验与第三方实测，属行业通用做法。

## 6. 特殊工艺 / 风味修饰

### 6.1 经典意式工艺差异

| 品类 | 工艺特点 |
| :--- | :--- |
| **Espresso 浓缩** | 单份 30 ml / 双份 60 ml，9 bar 压力、22~30 秒萃取，油脂层（Crema）约 10~15% |
| **美式 Americano** | 浓缩 + 热水稀释；中杯 1 份、大杯 2 份、Venti 2 份（热）/ 3 份（冰） |
| **拿铁 Latte** | 浓缩 + 蒸汽牛奶 + 薄奶泡（约 0.5 cm）；牛奶占比约 75% |
| **卡布奇诺 Cappuccino** | 浓缩 + 蒸汽牛奶 + **厚奶泡**（约 1 cm），传统意式做法奶泡更厚；星巴克门店版本略偏向「厚奶泡拿铁」 |
| **馥芮白 Flat White** | **Ristretto（加倍浓郁浓缩，限量萃取前段）+ 蒸汽牛奶 + 极薄奶泡**；咖啡浓度高于拿铁 |
| **焦糖玛奇朵 Caramel Macchiato** | 香草糖浆打底 + 浓缩 + 蒸汽牛奶 + 奶泡 + 焦糖酱「标记」（macchiato 意为「标记」） |
| **摩卡 Caffè Mocha** | 摩卡酱 + 浓缩 + 牛奶 + 打发奶油（whipped cream） |
| **浓缩玛奇朵 Espresso Macchiato** | 浓缩 + 微量奶泡「标记」 |

### 6.2 风味糖浆修饰

星巴克中国门店常用糖浆泵数默认值（来源为咖啡师指南）：

| 杯型 | 默认糖浆泵数 |
| :--- | :--- |
| 中杯 Tall | 3 泵 |
| 大杯 Grande | 4 泵 |
| 超大杯 Venti（热） | 5 泵 |
| 超大杯 Venti（冰） | 6 泵 |

常用糖浆：香草、焦糖、榛子、肉桂、薄荷、太妃坚果、覆盆子等。

### 6.3 「星善食 GOODGOOD」与可持续

- **燕麦奶推广**（2020 年起）：与 OATLY 合作，每杯燕麦奶替代牛奶饮品减排约 64% 温室气体（OATLY 披露）。
- **植物基默认化趋势**：2024 年起部分门店默认提供燕麦奶选项。
- **「好好照顾每一杯」服务承诺**（2026 年星巴克中国焕新）：强调服务、品质与可持续供应链（详见官网新闻）。

### 6.4 高蛋白拿铁 PRO（2026 新品线）

- 蛋白质含量：大杯约 20 g（约 3 个鸡蛋等量）。
- 0 乳糖（适合乳糖不耐受人群）。
- 蒙牛 EHT 酶水解专利技术处理。
