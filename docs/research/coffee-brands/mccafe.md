# 麦咖啡 McCafé · 基础方案调研

> 调研时间：2026-09-04
> 调研范围：中国大陆麦当劳门店内的「麦咖啡」柜台
> 信息源：详见第 7 节

> **业态说明**：麦咖啡在中国大陆以「**店中店**」形式为主——咖啡柜台设置在麦当劳餐厅内部，共享麦当劳的供应链、后厨动线、客流与外卖履约。这一点与 Costa、星巴克等独立门店咖啡品牌有本质差异，会影响出品（萃取节奏、奶泡温度、外带杯型）和价格区间。

## 1. 杯型容量（中国市场）

麦咖啡中国当前（2024-2026 年期间）门店主力杯型为 **中杯 / 大杯** 两档，**未设置超大杯**。与瑞幸、Manner 等小杯起家的品牌不同，麦咖啡沿用了麦当劳的「大杯文化」。

| 杯型 | 容量（热） | 容量（冰） | 备注 |
| :--- | :--- | :--- | :--- |
| 中杯 | 约 355 ml | 约 355 ml | 经典意式主推杯型 |
| 大杯 | 约 470 ml | 约 470 ml | 加价升级 |
| 超大杯 | **未公开** | **未公开** | 麦咖啡中国未上线超大杯 SKU，与麦当劳正餐可乐杯型不同 |

- **说明**：以上 ml 数为门店标准杯模量；外卖 / 自助点单可能因冰块占比存在 ±20 ml 浮动。
- **数据采集时间**：2026-09 之前；2023 年起麦咖啡门店扩张明显，杯型基本稳定在「中 / 大」两档。
- **不公开 / 待核实**：精确 ml 数未在官方页面以数字形式公开，第三方测评（什么值得买、小红书用户实测）多数报告为「中杯约 12 oz、大杯约 16 oz」口径（1 oz ≈ 29.57 ml），换算后近似上表数值。

## 2. Espresso 浓缩份数

麦咖啡中国经典意式（如「拿铁」「美式」「卡布奇诺」「摩卡」「焦糖玛奇朵」）的 Espresso 配方为：**中杯单份、大杯双份**。这一双档结构与麦当劳全球 McCafé 系统基本一致。

| 杯型 | 浓缩份数 | 单份 Espresso 量 | 总 Espresso 量 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| 中杯 | 1 份 | 约 18 g 粉 / 约 30 ml 液 | 约 18 g / 30 ml | 经典意式基准 |
| 大杯 | 2 份 | 约 18 g 粉 / 约 30 ml 液 | 约 36 g / 60 ml | 加价升级自动加 shot |
| 超大杯 | 不适用 | — | — | 未上线 |

- **重点事实**：大杯拿铁 / 美式 / 卡布 = **双份 Espresso**，与行业「中杯 1 / 大杯 2」通用规则一致，**不存在「大杯 3 份」的特殊设定**。
- **数据采集时间**：2025-2026 年麦当劳中国 App / 小程序点单界面显示一致。
- **不公开 / 待核实**：单份 Espresso 的精确咖啡粉克数与液量未在官方公开技术文档中标注；以上数值来自门店标准化出品与第三方测评近似值。

## 3. 咖啡豆

- **名称**：麦咖啡未单独命名「XX 拼配」豆品牌（如星巴克有 Pike Place、Costa 有 Mocha Italia），官方对外口径统一为「**麦当劳咖啡豆**」或「**麦咖啡精选拼配豆**」。
- **拼配 / 产地**：
  - 以「**阿拉比卡豆为主**」的拼配（arabica blend），官方多次强调「100% 阿拉比卡」。
  - **2020 年起麦当劳中国逐步增加云南咖啡豆采购比例**，2022 年官宣「**到 2025 年实现 100% 使用云南咖啡豆**」目标（"云南保山小粒咖啡"为主要来源）。
- **烘焙度**：中度偏深烘焙（medium-dark），适配意式萃取 + 牛奶搭配的苦甜平衡。
- **专利 / 自有**：麦咖啡中国未公开宣称「专利 / 自有豆」；但其在云南保山建立了长期直采关系。
- **金奖核实**：第三方测评（小红书、知乎）流传的「麦咖啡金奖豆」说法 **在麦当劳中国官方渠道未能找到对应证据**；金奖可能来自「国际咖啡品鉴大赛」「Coffee Review 高分单品豆」等单一批次宣传，**非全线产品的常态化卖点**。
- **专属拼配核实**：麦当劳官方未单独立项「麦咖啡专属拼配豆」品牌名；与「Costa Mocha Italia」「星巴克 Pike Place」「瑞幸 SOE 云南」等可命名的拼配相比，麦咖啡豆更偏向「**供应链层面的统一配方**」。
- **备注**：作为「店中店」品牌，麦咖啡豆的供应链与麦当劳全球咖啡采购体系对接，云南豆直采是其 ESG / 乡村振兴叙事的重要支点。

## 4. 奶源供应商

- **默认牛奶**：麦咖啡中国大陆默认使用 **低温鲜牛奶（巴氏奶）**，与麦当劳正餐的牛奶体系一致。
- **供应商 / 品牌**：
  - 麦当劳中国长期合作乳企为 **新希望乳业 / 蒙牛 / 光明** 等多家区域性供应商（不同省份、不同门店使用不同供应商，但均通过麦当劳统一品控标准）。
  - 「**新希望**」低温鲜奶是较常见的默认品牌之一（西南、华北门店）。
  - 「**蒙牛现代牧场**」在部分北方门店出现频率较高。
- **类型**：鲜牛奶（巴氏杀菌 / 低温冷藏），**非 UHT 常温奶**。
- **进口 / 国产**：**国产为主**。麦咖啡未公开使用进口常温奶作为默认奶源（与 Costa 部分门店使用 UHT 进口奶形成对比）。
- **燕麦奶 / 厚椰乳**：麦咖啡中国自 2022 年起在部分门店上线 **OATLY 燕麦奶** 作为替换选项（OATLY 为瑞典品牌，中国版由欧力（上海）生产），加价约 ¥4-6；厚椰乳采用国产椰浆品牌（如菲诺），用于部分季节限定产品。
- **备注**：作为「店中店」，麦咖啡共享麦当劳餐厅的冷链与配送体系，鲜奶保质期短、上货频次高；这也解释了麦咖啡对国产 / 区域乳企的依赖。

## 5. 默认温度

**重点结论**：麦咖啡中国 **没有产品级「默认冰」或「默认热」**——拿铁、美式、卡布、摩卡等经典意式在菜单上以 **「热饮 SKU」与「冰饮 SKU」并列** 的方式呈现，用户点单时主动选择冷热。

| 品类 | 默认温度 | 备注 |
| :--- | :--- | :--- |
| 拿铁（热 / 冰） | 用户自选 | 热、冰为独立 SKU；不存在「默认冰」 |
| 美式（热 / 冰） | 用户自选 | 麦当劳正餐套餐常以「热饮」为默认搭配项，麦咖啡单独点单时仍可选冰 |
| 卡布奇诺（热 / 冰） | 用户自选 | 冰卡布为独立 SKU |
| 摩卡（热 / 冰） | 用户自选 | — |
| 焦糖玛奇朵（热 / 冰） | 用户自选 | — |
| 馥芮白 / Flat White | 以热为主 | 部分门店冰版上线不稳定 |

- **关键否定**：网上流传的「麦咖啡默认冰」说法 **不成立**——这是用户体感而非产品规则。
- **数据采集时间**：2024-2026 年麦当劳中国 App / 微信小程序点单界面确认。
- **不公开 / 待核实**：部分季节性 / 区域限定 SKU 的冷热可售情况以门店实际为准。

## 6. 特殊工艺 / 风味修饰

- **「醇香」系列（2023 起）**：麦咖啡中国推出「**浓 / 醇 / 轻**」三档浓度选项，用户可在点单时调整咖啡浓度（浓 = 加重 espresso 萃取率 / 醇 = 标准 / 轻 = 减 shot）。
- **风味糖浆**：提供 **香草、焦糖、榛果** 三种主流糖浆（与星巴克、Tims 体系接近），部分门店季节性上线栗子、玫瑰、海盐焦糖等限定糖浆。
- **拉花**：作为「店中店」品牌，麦咖啡拉花 **不作为核心卖点**，门店员工培训以出品速度为核心；拉花覆盖率低于独立精品咖啡馆。
- **奶泡工艺**：使用全自动咖啡机自带的蒸汽棒打发牛奶，**未单独公开奶泡厚度标准**。
- **萃取设备**：麦咖啡中国大陆门店主力咖啡机为 **瑞士进口超全自动咖啡机**（业内广泛报道使用 **Franke**、**Thermoplan**、**WMF** 三家瑞士品牌的超自动机型，具体机型与门店签约年份相关）：
  - **Franke**：A600 / A800 系列（部分 2020 年后新开店使用）。
  - **Thermoplan**：Black & White 系列（部分华东、华南门店使用）。
  - **WMF**：1500 S+ / 5000 S 系列（部分北方及一线门店使用）。
  - **说明**：以上品牌信息为业内公开报道与第三方测评的综合，**未在麦当劳中国官网单独披露统一机型**；不同门店因翻牌 / 加盟体系差异存在机型混用。
- **店中店出品差异**：与独立门店咖啡品牌相比，麦咖啡的出品节奏更快（兼顾麦当劳正餐出餐），萃取参数偏向「稳定一致」而非「精品手作」。

## 关键发现

1. **店中店基因决定一切**：麦咖啡是「**寄生在麦当劳正餐体系**」的咖啡柜台，共享冷链、客流、外卖履约——这决定了它**走不出「性价比 + 稳定出品」的路线**，无法做精品手作。
2. **杯型只有两档（中 / 大），浓缩份数遵循「1 / 2」行业通用规则**，**不存在「大杯 3 份」的特殊加浓设定**——这一条消除了关于浓缩份数的常见误解。
3. **没有「产品级默认温度」**：网上「麦咖啡默认冰」说法 **不成立**，冷热是独立 SKU，由用户主动选择。
4. **咖啡豆无独立品牌名**：麦咖啡中国 **未单独命名「专属拼配豆」**，与 Costa Mocha Italia、星巴克 Pike Place、瑞幸 SOE 云南等可命名拼配对比，麦咖啡豆更偏「**供应链统一配方 + 云南豆直采**」叙事。
5. **奶源 100% 国产低温鲜奶**为主，与 Costa 部分门店使用 UHT 进口奶形成对比——这对 Nutri-Grade 计算时的蛋白、脂肪参数有直接影响（鲜奶蛋白含量通常更高）。
6. **咖啡机为瑞士超自动机**（Franke / Thermoplan / WMF 三家混用），**全自动萃取 + 蒸汽棒打奶**，出品节奏快但拉花不是重点。

## 无法核实的项（明确列出）

1. 中杯 / 大杯的 **精确 ml 数**（官方未公开数字，第三方为近似换算）。
2. 单份 Espresso 的 **精确咖啡粉克数与液量**（官方未公开技术文档）。
3. **超大杯 SKU** 是否在历史某段时间存在 / 未来是否上线（当前未上线）。
4. 麦咖啡中国是否拥有 **「专属拼配豆」独立品牌命名**（截至 2026-09 暂无）。
5. **「金奖豆」** 说法对应的官方奖项与年份（**官方渠道无证据**）。
6. **统一奶源供应商品牌**（因区域差异多家乳企并存，未公开统一品牌）。
7. **统一咖啡机机型**（因门店翻牌年份与加盟体系差异，Franke / Thermoplan / WMF 混用）。
8. 馥芮白（Flat White）冰版在 **全国门店的覆盖率**（上线不稳定）。
