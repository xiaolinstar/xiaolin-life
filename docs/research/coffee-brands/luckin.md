# 瑞幸 luckin coffee · 基础方案调研

> 调研时间：2026-09-03
> 调研口径：中国大陆市场门店（不含港澳台及新加坡等海外门店）
> 数据采集期：2025-09 至 2026-08（部分历史数据回溯至 2023-2024）
> 信息源：底部列出全部来源链接

## 1. 杯型容量（中国市场）

> 2026-01 起，瑞幸推行 “+3 元升杯” 策略，杯型体系从「单一大杯」升级为「大杯 / 特大杯 / 超大杯」三档；旧版小蓝杯（约 450ml）依然是大杯档默认规格。

| 杯型 | 容量 | 备注 |
| :--- | :--- | :--- |
| 大杯 | 约 450 ml（16 oz） | 经典意式（美式、拿铁、卡布）默认杯型，2026 升杯后仍为基线 |
| 特大杯（热饮） | 约 553 ml（20 oz） | 2026-01 上线，热饮升杯选项；含杯体冰 / 水扩容 |
| 超大杯（冰饮） | 约 596 ml（24 oz） | 2026-01 上线，冰饮升杯选项 |
| 小黑杯 / 精品杯 | 约 330 – 355 ml（12 oz） | SOE 单品系列（耶加雪菲、花魁、瑰夏、云南普洱）默认杯型 |
| 瓶装即饮 | 300 ml | 便利店销售（生椰拿铁、经典美式等） |
| 大师咖啡 / 经典意式 | 约 450 ml（大杯） | 瑞幸小程序点单界面公示：450 ml / 553 ml / 596 ml 三档 |

**来源冲突 / 备注**：
- 早期（2023-2025）瑞幸小蓝杯基本只有 16 oz 一档；小黑杯 12 oz；小鹿茶 22 oz。
- 上海市市场监督管理局抽检公示曾确认「大杯 450 ml」。
- 不同产品线实测略有差异（450 / 473 / 480 ml），16 oz 换算为 473 ml，瑞幸官方简化为 450 ml。
- 杯体标注为「含冰总容量」，去冰后液体量会明显减少（如 596 ml 超大杯去冰后实测约 300 ml）。

## 2. Espresso 浓缩份数

> 瑞幸主流意式（标准美式 / 经典拿铁 / 卡布 / 玛奇朵）默认 **单杯 1 份** Espresso；「大师系列」升级为 **2 份**；SOE 小黑杯使用 **单一份** SOE 萃取液。

| 品类 | 杯型 | 浓缩份数 | 单份 Espresso 量 | 总 Espresso 量 | 咖啡因参考 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 标准美式（大师系列） | 大杯 / 冰 | 1 份标准萃取 | 约 18 g 粉 → 约 40 g 浓缩液 | 约 40 g 浓缩液 + 水补足 | 约 164.3 mg |
| 加浓美式（大师系列） | 大杯 / 冰 | **2 份** Espresso | 约 21 g 粉 → 约 45 g 浓缩液 / 份 | 约 80 – 90 g 浓缩液 + 水补足 | 约 198.9 mg |
| 经典拿铁 | 大杯 / 热 | 1 份 | 约 18 g 粉 → 约 40 g 浓缩液 | 约 40 g 浓缩液 + 牛奶 | 约 98.6 mg |
| 玛奇朵 / 卡布 / 澳瑞白 | 大杯 | 1 份 | 约 18 g 粉 → 约 40 g 浓缩液 | 约 40 g 浓缩液 + 奶 / 奶泡 | 约 75 – 150 mg（按品类） |
| SOE 小黑杯（耶加雪菲美式） | 12 oz / 冰 | 1 份 SOE | 约 18 g 粉 → 约 36 g 浓缩液 | 约 36 g 浓缩液 + 水 | 不公开 |
| SOE 小黑杯（耶加雪菲拿铁） | 12 oz / 冰 | 1 份 SOE | 同上 | 约 36 g 浓缩液 + 牛奶 | 不公开 |
| 升杯（特大 / 超大） | — | **视品类单独调整** | 部分饮品按比例多加咖啡液 / 牛奶；部分仅扩容稀释 | — | — |

**重点核实结论**：
- 「加浓美式」官方明确标注 **「双份 Espresso 浓缩」**（瑞幸官网产品页 lkcoffee.com 与 lkcoffee.com/products/americanos/double-americano 均写明「双份 Espresso 浓缩，咖啡因含量约 198.9 mg / 杯」）。
- 「加浓」≠「加一份浓缩」：部分门店解释「加浓」是咖啡机切换「加浓浓度」按键，21 g 粉萃取 ≥ 45 g 液（比标准 18 g 粉 / 40 g 液更多），用户可在点单时再勾选「额外加浓缩」实现「加浓 + 浓缩」。
- 升杯（特大 / 超大）并非简单「加水 / 加奶」，但店员口径分歧明显，官方未公开统一调整公式。

**单份 Espresso 量来源**：
- 瑞幸未公开官方「单份 Espresso 粉量 / 液量」标准。
- 第三方实测（咖啡爱好者）：18 g 粉 → 40 g 浓缩液（标准浓度）；21 g 粉 → ≥ 45 g 浓缩液（加浓浓度）。
- 网友讨论引用：「瑞幸 16 oz 的咖啡用 21 g 粉萃取 43 – 48 g 咖啡液」。

**未核实 / 不公开**：
- 中杯 / 小杯标准美式 / 经典拿铁的单份 Espresso 粉液比（瑞幸已下线小杯，2026 年无官方小杯数据）。
- 玛奇朵 / 卡布 / 焦糖玛奇朵等「奶咖 / 糖浆咖啡」的具体 Espresso 粉液比。
- 各 SOE（花魁 / 瑰夏 / 云南普洱）单品的小黑杯 Espresso 粉液比。

## 3. 咖啡豆

### 3.1 常规意式拼配（蓝杯 / 大师系列基础豆）

- **名称**：瑞幸 IIAC 金奖意式拼配豆（官方称「大师级定制 Espresso 源自 IIAC 金奖咖啡豆」）
- **拼配 / 产地**：100% 阿拉比卡，**埃塞俄比亚 + 巴西 + 哥伦比亚 + 危地马拉 + 中国云南**（WBC 冠军团队调配）
- **烘焙度**：深度烘焙 / 中深烘焙（IIAC 认证 ICT 87+ 高分金奖配方）
- **专利 / 自有**：
  - **连续 7 – 8 年获 IIAC 国际咖啡品鉴大赛金奖**（2018 – 2024 / 2025 不同口径）
  - **连续 7 年**：截至 2024 年 11 月 IIAC 颁奖时，瑞幸连续 7 年摘金；**连续 8 年**：2025 年瑞幸官方产品页（lkcoffee.com）口径
  - 2021 IIAC 意式拼配豆获 **ICT 87+ 金奖**
  - 2025 年瑞幸意式拼配豆成为 **WLAC（世界拉花艺术大赛）唯一指定用豆**
  - 2025 年获 **年度国际美味奖**（食品界「奥斯卡」）
- **烘焙基地**：
  - 福建宁德烘焙基地（2021 投产，投资 2.1 亿元，4.5 万 ㎡，年产能 1.5 万吨）
  - 江苏昆山烘焙基地（年产能 3 万吨，占全国咖啡烘焙产能近 20%）
  - 山东青岛创新生产中心（在建）
  - 云南保山鲜果处理加工厂（2024-03 投产）
- **采购**：
  - 2025-2029 计划从巴西采购 24 万吨，总价值 100 亿元
  - 2023 启动「全球寻豆之旅」，已覆盖埃塞俄比亚、巴拿马、印度尼西亚、中国云南、巴西
- **风味描述**：饱满坚果基调 + 浓郁焦糖香 + 尾韵松木风味；莓果芳香、烤坚果韵味
- **备注**：原 IIAC 金奖意式拼配豆于 2021 年以 ICT 87+ 高分斩获；为 WLAC 2025 唯一指定用豆

### 3.2 埃塞金烘（2026-04 新增客制化选项）

- **名称**：埃塞金烘系列（瑞幸 IIAC 铂金奖咖啡豆 + 专属梯度升温烘焙）
- **拼配 / 产地**：埃塞俄比亚单一产区阿拉比卡
- **烘焙度**：浅中烘（区别于常规意式拼配的深烘 / 中深烘）
- **烘焙师**：WBC 2025 世界亚军 **孙磊** 推荐
- **覆盖饮品**：加浓美式、橙 C 美式、小黄油拿铁、精萃澳瑞白、轻椰茉莉拿铁、茉莉花香拿铁等 20+ 核心饮品
- **新单品**：埃塞金烘美式、埃塞金烘拿铁
- **风味描述**：花香 + 黑巧调性 + 甜感，浓醇均衡

### 3.3 SOE 小黑杯（精品单一系列）

| 豆款 | 产地 | 烘焙度 | 风味 | IIAC 奖项 |
| :--- | :--- | :--- | :--- | :--- |
| 耶加雪菲 SOE | 埃塞俄比亚·耶加雪菲（水洗） | 中深烘（SCA 80+） | 柑橘 / 茉莉花 / 太妃糖 / 牛奶巧克力 / 坚果尾韵 | **2021 / 2023 IIAC 铂金奖**（最高奖项） |
| 花魁 SOE | 埃塞俄比亚·罕贝拉 | 中度烘焙 | 热带水果（草莓、水蜜桃）、层次丰富 | IIAC 金奖 |
| 瑰夏 SOE | 埃塞俄比亚·班其玛吉 / 巴拿马 | 中度烘焙 | 花香 / 柑橘 / 莓果酸甜 / 茶感 | IIAC 金奖 |
| 云南普洱 SOE | 中国云南·普洱 | 中深烘焙 | 小柑橘柔和酸 / 红糖甜 / 黑巧克力 | IIAC 金奖 |
| 云南小甘橘系列 | 中国云南 | — | 搭配澳瑞白 / 拿铁 / 美式 / Dirty | 季节性精品系列 |

- **特色卖点**：耶加雪菲 SOE 是「全球唯一获 IIAC 铂金奖的单一产地咖啡豆」（2021、2023 两度摘铂金）。
- **杯型**：小黑杯约 12 oz（330 – 355 ml）。
- **门店限定**：早期仅北京、上海及主题店，2025-2026 已扩展至全国主要门店。

### 3.4 浅烘美式（2026 新增）

- **名称**：浅烘美式（WBC 冠军推荐）
- **烘焙度**：浅烘
- **定位**：保留原产地风味、明亮酸净；WBC 2025 世界亚军孙磊力推
- **意义**：打破瑞幸「中深烘 + 深烘」单一豆谱，向精品化延展

## 4. 奶源供应商

> 瑞幸奶源采用 **多元供应商模式**，按产品线和乳制品类型分配；2026 年起在部分门店试点 **「鲜奶升级」**（常温奶 → 14 天保质期冷链鲜奶）。

### 4.1 经典拿铁 / 标准意式（基础纯牛奶）

- **默认牛奶**：纯牛奶（常温 UHT 为主，2026 起部分门店切换为鲜奶）
- **供应商 / 品牌**：
  - **三元股份**（北京商报 2023-09 投资者互动平台官方确认：三元股份是瑞幸咖啡的纯牛奶供货商之一）
  - 蒙牛 / 伊利 常温纯牛奶（行业横向评测常用供应商）
  - **蒙牛每日鲜语**（上海 200+ 门店 2026-04 起切换为冷链鲜奶）
  - **特仑苏专属牧场奶源**（2026 春节期间经典拿铁系列升级使用）
  - **恒天然**（全球乳业巨头，供应基础鲜奶及部分高端乳制品）
  - **认养一头牛**（主要用于奶盖、芋泥等辅料）

### 4.2 厚乳系列

- **供应商**：**宁夏塞尚乳业**（独家 / 主要）
- **工艺**：低温膜分离技术 / 纳米级有机生物膜分离浓缩
- **应用**：
  - 酱香拿铁白酒风味厚乳（独家供应）
  - 冷萃厚牛乳（专为冰饮设计）
  - **北海道丝绒风味厚奶**（小分子膜分离工艺，呈现北海道牛乳的丝滑口感、柔和甜感、浓郁奶香）—— 用于丝绒拿铁系列（北海道蜜瓜丝绒拿铁、生椰丝绒拿铁、香草丝绒拿铁、四国柚子丝绒拿铁等）

### 4.3 椰乳

- **供应商**：**菲诺**（厚椰乳）
- **应用**：生椰拿铁（瑞幸首创，全球累计销量超 20 亿杯）
- **来源**：东南亚成熟生椰，1 小时冷榨锁鲜

### 4.4 特殊乳制品

- **马斯卡彭芝士**：丹麦进口（用于马斯卡彭生酪拿铁，《猫和老鼠》联名款）
- **黄油**：新西兰进口（用于小黄油拿铁 / 小黄油美式）
- **奶酪**：新西兰进口（用于全冰奶酪美式）

### 4.5 鲜奶升级试点（2026-04 起）

- **覆盖**：上海约 200 家门店（2026-04 数据）
- **品类**：拿铁、澳瑞白、玛奇朵等部分饮品标注「鲜奶」标识
- **切换**：常温长效牛奶 → 14 天保质期冷链鲜奶
- **价格**：保持 9.9 元（领券后）不上涨
- **官方回应**：瑞幸客服称「目前鲜奶饮品是部分门店、部分饮品限时售卖，并非所有门店都支持，具体以系统显示为准」

### 4.6 类型与产地

- **类型**：常温 UHT 纯牛奶（基础）+ 鲜奶 / 冷链鲜奶（升级试点）+ 厚乳（塞尚膜分离）+ 椰乳（菲诺）+ 进口芝士 / 黄油
- **进口 / 国产**：基础牛奶以国产（三元、蒙牛、伊利、认养一头牛）为主；马斯科彭芝士（丹麦）、黄油 / 奶酪（新西兰）为进口；恒天然（新西兰）提供部分高端乳制品

## 5. 默认温度

> 瑞幸点单界面默认温度逻辑：**美式默认热**、**拿铁 / 奶咖默认热**、**SOE 小黑杯 / 鲜果咖默认冰**。2025-08 网友吐槽「小程序点单推荐冰但默认热」，客服回应「因美式咖啡中热饮选择比例较高，系统默认设置为热饮」。

| 品类 | 默认温度 | 备注 |
| :--- | :--- | :--- |
| 标准美式（大师系列） | **热**（系统默认） | 网友实测 2025-08 吐槽「推荐冰但默认热」；瑞幸客服称无法更改 |
| 加浓美式（大师系列） | 热 / 冰均可（官方页面以大杯 / 冰展示） | 营养公示卡按「大杯 / 冰」口径公布 |
| 经典拿铁 | 热 / 冰均可（官方页面以大杯 / 热展示） | 营养公示卡按「大杯 / 热」口径公布 |
| 卡布奇诺 / 玛奇朵 / 焦糖玛奇朵 | 热 / 冰均可 | — |
| 澳瑞白（大师系列） | 热 / 冰均可 | — |
| SOE 小黑杯（耶加雪菲 / 花魁 / 瑰夏 / 云南普洱） | **冰** 为主 | 冷饮风味表现更优；部分门店可制热 |
| 鲜果咖（橙 C / 柚 C / 苹果 C 美式） | **冰** | 季节性产品，主打冰饮 |
| 升杯（特大 / 超大） | 冷饮走超大、冰饮 | 热饮走特大 |

**特殊默认逻辑**：
- 大师美式类：系统默认热，但推荐弹窗会推荐冰，需手动切换
- 大师拿铁 / 奶咖：热 / 冰均默认 1 份 Espresso，不因温度变化
- 去冰处理：瑞幸客服称「若产品支持去冰，咖啡师制作时不再添加冰块，饮品中空余容量会采用产品主要原料补齐」

## 6. 特殊工艺 / 风味修饰

### 6.1 烘焙工艺

- **意式拼配深烘**：常规蓝杯 / 大师系列基础豆，深度烘焙，呈现莓果芳香、焦糖回甘、奶油顺滑、烤坚果韵味
- **埃塞金烘（2026-04 新增）**：浅中烘，**专属梯度升温烘焙工艺**，激发并平衡铂金豆原有花香、黑巧调性及甜感
- **浅烘美式（2026 新增）**：浅烘曲线，保留原产地风味、明亮酸净
- **WBC 冠军团队**：Boram Um（2023）、Anthony Douglas（2022）、Agnieszka Rojewska（2018）、井崎英典（2014）、Andrea Lattuada（2003）、潘志敏（2017 中国冠军）共同背书

### 6.2 萃取工艺

- **瑞斯奇托精萃工艺**（Ristretto）：更少水量、更短时间、更前段位置萃取，咖啡甜感更明快、风味更丰富
- **加浓萃取**：21 g 粉 → ≥ 45 g 浓缩液（vs 标准 18 g 粉 → 40 g 液）
- **SOE 萃取**：单一产地咖啡豆，新鲜研磨，呈现花果香和原产地特色
- **WLAC 2025 标准**：作为世界拉花艺术大赛唯一指定用豆，萃取油脂丰富、表面光亮，搭配牛奶时拉花图案清晰

### 6.3 奶基底工艺

- **小分子膜分离工艺**（塞尚乳业）：用于北海道丝绒风味厚奶，呈现北海道牛乳的丝滑口感、柔和甜感、浓郁奶香
- **冷萃厚牛乳**（欧必客）：专为冰饮设计，提升冷萃咖啡的醇厚度
- **生椰冷榨**：1 小时冷榨锁鲜工艺，菲诺厚椰乳
- **鲜奶升级**：14 天保质期冷链鲜奶替代常温长效奶（上海试点）

### 6.4 风味修饰

- **钻石冰**（全冰去水系列）：冰晶致密、纯净少气泡、高硬度、持久耐融，搭配饮品风味不易稀释
- **全冰去水**：「不加饮用水 + 多加冰」点单技巧，可减少清水稀释（用户自创，瑞幸门店接受备注）
- **埃塞金烘选项**：可对 20+ 核心饮品切换为埃塞金烘豆基（免费客制化）
- **季节性风味**：橙 C、柚 C、苹果 C 等 NFC 果汁美式；小青桔、芒芒青提等鲜果咖

## 调研结论摘要

### 数据点统计

- **杯型容量**：5 个标准杯型档位（大杯 / 特大杯 / 超大杯 / 小黑杯 / 瓶装即饮）
- **浓缩份数**：6 个核心品类（标准美式 / 加浓美式 / 经典拿铁 / 玛奇朵卡布澳瑞白 / SOE 小黑杯 / 升杯策略）
- **咖啡豆**：1 套意式拼配深烘豆 + 1 个埃塞金烘浅中烘 + 4 款 SOE 单品（耶加雪菲 / 花魁 / 瑰夏 / 云南普洱）+ 1 个浅烘美式 + 1 个季节性云南小甘橘系列
- **奶源供应商**：4 家主要乳企（三元 / 蒙牛 / 恒天然 / 认养一头牛）+ 1 家厚乳独家（塞尚乳业）+ 1 家椰乳独家（菲诺）+ 2 类进口乳制品（丹麦马斯卡彭、新西兰黄油奶酪）
- **默认温度**：3 大类默认逻辑（美式默认热 / SOE 默认冰 / 鲜果咖默认冰）
- **特殊工艺**：4 大类（烘焙工艺 / 萃取工艺 / 奶基底工艺 / 风味修饰 + 杯型策略）

### 关键发现

1. **「大师系列」是瑞幸意式咖啡的品质基线**：连续 7-8 年获 IIAC 金奖（2018-2025），2025 年成为 WLAC 世界拉花大赛唯一指定用豆；常规意式拼配由 100% 阿拉比卡（埃塞 / 巴西 / 哥伦比亚 / 危地马拉 / 中国云南）深度烘焙。
2. **「加浓美式」是双份 Espresso 浓缩的明确代表**：官方产品页明确写「双份 Espresso 浓缩，咖啡因 198.9 mg / 杯」；而「标准美式」为单份（约 164.3 mg / 杯咖啡因）。
3. **奶源采用「多元供应商 + 鲜奶升级」策略**：基础拿铁以三元 / 蒙牛常温奶为主（2026 起上海门店升级为蒙牛每日鲜语冷链鲜奶），厚乳独家塞尚乳业，椰乳独家菲诺。
4. **2026 年瑞幸加速「专业化」转型**：升杯（+3 元）、埃塞金烘浅中烘、浅烘美式、孙磊（WBC 2025 亚军）加入、丝绒拿铁 / 北海道系列厚奶工艺升级 — 不再只打「9.9 元性价比」牌。
5. **SOE 小黑杯容量偏小**（约 330 ml），与大师系列大杯（约 450 ml）形成「精品 vs 日常」两条产品线。

### 无法核实 / 待补充项

- **单份 Espresso 粉量 / 液量** 的官方标准（瑞幸未公开具体参数，第三方实测为 18 g 粉 / 40 g 浓缩液）
- **中杯 / 小杯** 的瑞幸官方杯型（2026 年起基本退市，仅 SOE 小黑杯保留 12 oz 杯型）
- **玛奇朵 / 卡布 / 焦糖玛奇朵 / 澳瑞白** 的官方 Espresso 浓缩份数（仅有咖啡因参考，未明示单份 / 双份）
- **「北海道生牛乳」与「朝日唯品」是否实际供应瑞幸**：搜索结果仅显示朝日唯品供应 Manner / M Stand 等精品咖啡馆；瑞幸「北海道丝绒风味厚奶」实为塞尚乳业用「北海道工艺」自产，并非直接采购北海道生牛乳
- **「北海道生牛乳」**：未找到瑞幸门店直接使用北海道产原奶的证据；瑞幸「北海道系列」实为「北海道工艺 / 风味」厚奶（塞尚乳业小分子膜分离工艺），并非真正的北海道进口生乳
- **瑞幸 2023-2026 期间奶源是否全部切换为鲜奶**：上海 200+ 门店 2026-04 起试点，全国推广时间未定
- **瑞纳冰 / 季节性 SKU 的浓缩份数与杯型**：本次未深入核实
