# 连锁咖啡品牌基础方案调研

> **调研目的**：把各连锁咖啡品牌的「经典意式咖啡」基础方案摸清楚，作为后续饮品测评内容的事实底座。
> **调研时间**：2026-09-03 → 2026-09-04
> **调研背景**：茶咖 / 奶咖流行，但经典意式（拿铁、美式、卡布、玛奇朵）经久不衰；内容创作需要事实基线。
> **调研方法**：Web 检索 + 官方信息核实 + 行业资料交叉验证。
> **关键认知修正**：用户原命题中部分供应商假设（恒天然 / 现代牧业作为星巴克供应商）经核实**不成立**。

## 调研维度

每个品牌都按统一模板记录以下 7 个维度：

1. **杯型容量**：中杯 / 大杯 / 超大杯的 ml 数（**中国市场当前标准**）
2. **Espresso 浓缩份数**：每杯含几份 Espresso，按杯型分别记录（**关键事实**）
3. **咖啡豆**：产地、拼配豆名称、烘焙度、专利 / 自有豆
4. **奶源供应商**：默认牛奶的品牌、供应商、进口 / 国产
5. **默认温度**：热 / 冰 / 可选（按品类分别记录）
6. **特殊工艺 / 风味修饰**：如 Costa 的 Mocha Italia、星巴克的 Pike Place 等
7. **信息源**：每个事实标注来源链接（官方 / 权威媒体 / 第三方核实）

## 重点核查项结论（用户预判 vs 实际）

| 用户预判 | 实际核实结论 | 证据 |
| :--- | :--- | :--- |
| Costa 大杯拿铁 3 份浓缩 | **基本成立**（按 Costa UK 官方 2026 Caffeine Guide：Large Latte = 3 shots；Cappuccino/Mocha/Americano Large = 4 shots）；**但中国市场官方未公开明示** | [costa.md §2.2](./costa.md) |
| 星巴克大杯和超大杯 2 份浓缩 | **部分成立**：大杯 Grande 2 份 ✓；超大杯 Venti **热饮 2 份** ✓；**冰 Venti 拿铁 / 美式默认 3 份**（因冰稀释多加 1 份） | [starbucks.md §2.3](./starbucks.md) |
| 恒天然 / 现代牧业作为星巴克供应商 | **不成立**：未发现两者作为星巴克中国牛奶直接供应商的官方披露。星巴克中国 2007 起全国主线是**蒙牛**；区域（卫岗 / 光明 / 发喜 / 安佳）；OATLY 独家 | [starbucks.md §4.1](./starbucks.md) |
| 经典咖啡经久不衰 | **确认成立**：所有 6 品牌的「经典意式」SKU 均保留并为销量主力；Costa/Stabucks/Manner 还在持续升级基础豆（如 Manner MANNER BLEND、星巴克 Blonde Roast、瑞幸埃塞金烘） | 全 6 份报告 |

**用户其他隐含假设补充**：

- 麦咖啡"默认冰"说法 **不成立**：mcdonalds.com.cn 官方菜单显示冰热是独立 SKU，用户主动选择，无产品级默认机制。
- Manner 美式**所有杯型均 2 份浓缩**（差异在加水量）—— 与 Costa/星巴克"中杯 1 / 大杯 2"逻辑不同，是 Manner 独特点。

## 关键对比洞察

### 浓缩份数逻辑对比

- **Costa**：中 2 / 大 3 / 卡布摩卡 4（基于 UK 官方）；最「重口」
- **星巴克**：中 1 / 大 2 / Venti 冰 3（唯一按冷热分）；标准美式口径
- **瑞幸**：大杯 1 份基础 + 「加浓」2 份选项；最经济
- **Manner**：美式**所有杯型 2 份**；拿铁按杯型递增（1/2/3）；独树一帜
- **Tims**：未公开（保守）
- **麦咖啡**：中 1 / 大 2；最简洁

### 咖啡豆策略对比

- **可命名**（自有标志性豆）：Costa Mocha Italia / 星巴克 Pike Place、Espresso Roast / 瑞幸 IIAC 金奖拼配、Manner BLEND
- **不可命名**：Tims 经典配方（称「只有三位大师知晓」）/ 麦咖啡「精选拼配」+ 云南豆直采

### 奶源策略对比

- **国产化**：Costa（澳亚牧场，国产奶源）+ 星巴克（蒙牛）+ 瑞幸（三元/蒙牛）+ Manner（朝日唯品）+ 麦咖啡（新希望/蒙牛/光明）—— 5 家国产奶源
- **不公开**：Tims
- **特殊合作**：OATLY 独家出现在星巴克 + 麦咖啡；瑞幸厚乳找塞尚、椰乳找菲诺

### 咖啡机策略对比（最关键分野）

- **半自动精品派**：**仅 Manner**（La Marzocco Linea PB）—— 业内唯一坚持半自动
- **超自动标准化派**：**麦咖啡**（瑞士 Franke / Thermoplan / WMF）+ 瑞幸
- **未披露**：Costa / 星巴克 / Tims（但根据行业惯例，这三家均为自有 Mastrena / 自有烘焙机）

## 调研方法论与纪律

- **优先官方信息源**：品牌官网 > 品牌官方公众号 / App > 权威媒体（虎嗅、晚点、第一财经）> 第三方测评（仅做交叉验证）
- **明确时间点**：注明数据采集时间（2026-09 之前 vs 之后）
- **拒绝凭空**：查不到就标「不公开 / 待核实」，**不臆测**
- **中国市场口径**：所有容量、浓缩份数以**中国市场门店**为准（非美国 / 总部口径）
- **冲突标注**：不同来源冲突时列出所有版本，不武断选一个
