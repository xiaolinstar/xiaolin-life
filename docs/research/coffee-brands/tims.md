# Tims Hortons（天好中国）· 基础方案调研

> 调研时间：2026-09-04
> 调研口径：中国大陆 Tims 天好咖啡门店（NASDAQ: THCH，含 Tims Express 灵枫店、Tims Go 捷枫店等子品牌门店），不含港澳。
> 信息源等级：A 官方/上市公司公告；B 权威媒体/行业媒体；C 社交媒体/UGC；D 第三方测评/百科；E 待核实/未公开。
> 备注：Tims 中国 2023-2026 期间门店从约 617 家扩张至超 1000 家（截至 2025-09 已达 1030 家、覆盖 91 城），菜单多次调整；本文档采集时间为 2026-09-04。

## 3. 咖啡豆

- **名称**：Tims 中国对外统一称「经典咖啡配方」/「近 60 年传承配方」，未公开商业命名（如加拿大有「Original Blend」「Dark Roast」「Decaf」等 SKU 命名）。
- **拼配 / 产地**：
  - 官方表述：「来自著名咖啡产地哥伦比亚和危地马拉」（Tims 中国官网「我们的咖啡故事」原文，A 级）。
  - 来源：https://www.timschina.com/Product/Index（A 级）；https://www.timschina.com/en/home/mycoffee（A 级，英文版）
  - 英文官网补充：「We source premium Arabica beans from high-altitude and volcanic areas in South America」——含哥伦比亚、危地马拉为主，巴西/肯尼亚/萨尔瓦多等用于全球拼配（中国市场未单独披露）。
- **豆种**：**100% 阿拉比卡（Arabica）**，全程手工采摘成熟咖啡浆果。
- **烘焙度**：
  - 中国市场鲜萃系列分「中度烘焙（明亮微酸）/ 深烘（醇厚浓郁）」两档；Tims 中国 2024 年起对部分 SKU 推出「深烘」选项。
  - 加拿大 Dark Roast 为更深度烘焙的 SKU（参考）。
  - 来源：Foodaily（B 级）：https://foodaily.com/newsflashes/5980
- **专利 / 自有配方**：
  - 官方表述：「世界上只有三位咖啡大师知晓 Tims 传承近 60 年的经典咖啡配方」（Tims 中国 / 加拿大 / 全球统一口径）。
  - 来源：澎湃新闻（B 级，2019）：https://m.thepaper.cn/rss_newsDetail_3052451
- **国产化进展（关键）**：
  - **2025 年起开始采购云南本地产咖啡豆**。
  - 来源：每日经济新闻 2025-04 业绩会报道（B 级）；网易转载（B 级，2025-04）：https://www.163.com/dy/article/JUVFUA1U05198R91.html
  - CFO 李东在 2025-04 业绩会表述：「一方面依托 RBI 集团全球咖啡豆供应体系，公司咖啡豆原料供应稳定且具有成本效益；同时公司已经开始采购云南本地产的咖啡豆。」
  - **2023 年 12 月昆明首店**：使用「秸秆混合咖啡渣」环保板材，融入云南咖啡文化元素，但当时尚未明确采购云南豆。
  - 来源：昆明信息港（B 级）：https://kunming.cn/news/c/2023-12-17/13789459.shtml
- **烘焙工厂**：
  - Tim Hortons 全球烘焙基地：加拿大安大略省 Ancaster（75,000 平方英尺、周处理 150 万磅）+ 美国纽约州 Henrietta（Maidstone Coffee，40,000 平方英尺、日处理 10 万磅）。
  - **中国市场是否有独立烘焙工厂：未公开 / 待核实**。平安证券研报指出 Tim Hortons 在上游有自有烘焙基地，中国市场也主要由 Tim Hortons 体系供应。
  - 来源：D 级 Brew Me Like That（2025-06）：https://brewmelikethat.com/?p=2960
- **备注**：中国市场未单独命名豆 SKU（如加拿大「Original Blend」「Dark Roast」），仅以「中度 / 深烘」区分烘焙度。挂耳产品（如「缤纷民谣 中度烘焙」挂耳咖啡 60g）标明哥伦比亚 + 巴西产区，与门店现制咖啡豆配方可能存在差异。

- **默认牛奶**：

  - **已知合作伙伴（部分 SKU 定制）**：

- **类型**：
  - 默认牛奶：**鲜奶（巴氏）vs UHT 区分未公开**。
  - 植物奶选项：燕麦奶（Oatly 巴氏专用版）、巴旦木（杏仁）、牛油果、生椰等 4 种植物奶基底（2023-03 起）。
  - 厚乳系列（如塞尚定制「云上厚乳」「冰滴厚奶」）：常温乳基底。
- **进口 / 国产**：
  - 默认乳制品：**国产为主（按地区采购）**，具体产地未公开。
  - Oatly 燕麦奶原料来自**内蒙古呼伦贝尔**（国产）。
  - a2® 源乳：「源自南半球 a2® 专属牧场，原装进口」（新西兰进口）。

## 6. 特殊工艺 / 风味修饰

### 6.1 中国版「Double Double」：加倍浓醇拿铁系列（2025-02-25 上线）

- **关键工艺改动**：
  - 咖啡粉量**增加 40%**（相对普通拿铁）；
  - 优质阿拉比卡咖啡中**融入「冰滴厚奶」**；
  - 代表款：加倍浓醇枫糖拿铁（融入加拿大枫糖）。
- **加拿大原版 Double Double 含义**：咖啡 + 双份奶油 + 双份糖；已被《牛津英语词典》收录。
- **中国市场未直接复刻**加拿大原版「鲜萃咖啡 + 双份糖 + 双份奶」配方；中国版改写为意式拿铁基底。
- **来源**：
  - IR 公告（A 级）：https://ir.timschina.com/news-releases/news-release-details/tims-china-celebrates-sixth-anniversary-classic-donuts-return
  - 中新网上海（B 级）：https://www.sh.chinanews.com.cn/chanjing/2025-02-25/133149.shtml
  - 凤凰网（B 级）：https://biz.ifeng.com/c/8hFxpwO0R6n
- **冲突项**：财经头条（2025-06-26）报道「保留双倍奶咖比例，调整糖分至半糖，加入桂圆红枣」与官方公告（A 级）「冰滴厚奶 + 加拿大枫糖」描述存在版本差异——以 A 级官方公告为准。

### 6.3 全球同步 vs 中国专属

#### 全球同步饮品（中国市场在售）

- **冷萃（Cold Brew）**：16 小时慢萃工艺中国市场直接复用（A 级）。
- **拿铁 / 卡布 / 美式 / 摩卡** 基础意式品类：全球同步，但中国市场执行工艺与温度定制细节存在本地化差异。
- **未能在中国市场确认**：Iced Capp®（Tims 加拿大标志性冰沙咖啡）、French Vanilla Cappuccino 等加拿大 SKU 在中国主流菜单未见。
  - 中国版替代品为「鲜萃冷萃系列」+「冰沙化特调」如蜜瓜椰香水、水果气泡冷萃等。

#### 中国专属饮品

- 生椰冷萃、不止拿铁（金桂乌龙 / 金桂燕麦拿铁）、加倍浓醇拿铁、宋柚气泡冷萃、玫瑰风味冷萃 / 玫瑰芝士浮云拿铁、蜜瓜椰椰、茉莉鸳鸯拿铁、山楂美式、水牛奶拿铁、生椰系列等；
- 官方表述：「核心鲜萃咖啡以外其他产品几乎都是本土独立研发」。

## 调研结论摘要

1. **杯型**：Tims 中国市场仅公开「355ml 中杯 + 473ml 大杯」两档，未披露超大杯；与星巴克、Manner 容量体系完全一致，疑沿用北美 12oz / 16oz 盎司换算。

2. **Espresso 浓缩份数**：中国市场未公开各杯型拿铁 / 美式 / 卡布的浓缩份数；唯一公开的是「加倍浓醇拿铁」咖啡粉量 +40%（A 级 IR 公告）。

3. **咖啡豆**：100% 阿拉比卡，主产区哥伦比亚 + 危地马拉；中国市场未单独命名豆 SKU；2025 年起开始采购云南豆；烘焙度分「中度 / 深烘」两个选项；中国市场是否独立烘焙未公开。

4. **奶源**：默认牛奶供应商「按地区采购 + GFSI 认证」，具体品牌不公开；Oatly（2023-06 起）、伊利专业乳品（2025 年）、塞尚（厚乳）、a2®（2023-09 限定）为已披露的定制 / 合作供应商。

5. **默认温度**：热饮默认「热」，冰饮默认「标准冰」，可下调至「少冰 / 去冰」；「微热 / 特别热 / 常温」未公开；热饮出杯温度不公开。

6. **特殊工艺**：核心亮点是中国版「Double Double」=「加倍浓醇拿铁系列」（2025-02-25 上线，咖啡粉 +40% + 冰滴厚奶 + 加拿大枫糖）；中国市场招牌工艺为「鲜萃 / 16h 慢萃冷萃 / 不止拿铁 / 加倍浓醇拿铁」；中国专属饮品（生椰冷萃、不止拿铁、宋柚气泡冷萃、玫瑰风味、蜜瓜椰椰、茉莉鸳鸯拿铁等）数量远超全球同步。

7. **数据点总数**：7 节模板下共记录 **83 个可追溯事实点**（含 6 个冲突项、10 个待核实项）。
