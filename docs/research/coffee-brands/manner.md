# Manner Coffee · 基础方案调研

> 调研时间：2026-09-03
> 数据采集口径：中国大陆直营门店（截至 2026-09）
> 信息源：见文末「信息源」一节，每个事实标注来源链接

## 1. 杯型容量（中国市场）

Manner 中国市场采用 **小杯 / 大杯 / 超大杯** 三档（不是中杯起步），且 **热饮和冰饮的容量存在差异**。这是 Manner 与星巴克、瑞幸最大的杯型差异。

| 杯型 | 容量（热饮） | 容量（冰饮） | 备注 |
| :--- | :--- | :--- | :--- |
| 小杯 | 约 237 ml（8 oz） | 一般不提供 | 早期标注曾为 240 ml / 360 ml，现统一按美制盎司换算 |
| 大杯 | 约 355 ml（12 oz） | 约 355 ml（12 oz） | 主力杯型，热 / 冰通用 |
| 超大杯 | 约 473 ml（16 oz） | 一般不提供 | 仅热饮超大杯；冰饮一般最大到大杯 |

**关键事实**：

- 小杯 8 oz、大杯 12 oz、超大杯 16 oz，均以 **美制液体盎司换算** 为 ml（1 oz ≈ 29.57 ml），故出现 237 / 355 / 473 等“有零有整”的数字。
- 早期（2021 年前后）部分门店 / 报道曾标注“小杯 240 ml、大杯 360 ml”，属于早期型号的近似值，现已统一为 237 / 355 / 473 ml。
- 历史公开报道中“473 ml 大杯”实为“超大杯”，**与现今菜单标签需区分**（见「信息源冲突」一节）。
- 2025-12 网络讨论“同价（15 元）小 / 大 / 超大杯”系大中小杯美式相同浓缩、不同水量策略，属于营销策略而非容量定义。

## 2. Espresso 浓缩份数

按杯型区分的标准浓缩规则（来源：Manner 兼职员工整理 / 内部培训手册二次流出）：

| 品类 | 杯型 | 浓缩份数 | 单份 Espresso 量 | 总 Espresso 量 |
| :--- | :--- | :--- | :--- | :--- |
| **常规美式 / 多数风味美式**（橙美式、葡美式、话梅美式、干姜美式等） | 大杯 / 超大杯 | **2 份** | 约 30 ml / 份（双份粉量 25 g，萃取 36–50 ml 浓缩液） | 约 60 ml |
| 冰橙茉莉美式（特例） | 大杯 | 1.5 份 | — | — |
| **常规拿铁 / 冰拿铁**（含仅加糖浆的风味拿铁） | 小杯 | 1 份 | 约 30 ml / 份（粉量 18–20 g） | 约 30 ml |
| 常规拿铁 / 冰拿铁 | 大杯 | 2 份 | 同上 | 约 60 ml |
| 常规拿铁 / 冰拿铁 | 超大杯 | 3 份 | 同上 | 约 90 ml |
| **含芝士 / 厚牛乳 / 厚乳的风味拿铁** | 大杯 | 1.5 份 | — | — |
| 含芝士 / 厚牛乳 / 厚乳的风味拿铁 | 超大杯 | 2 份 | — | — |
| **SOE 拿铁**（单一产地浓缩） | 小杯 | 1.5 份 SOE | — | — |
| SOE 拿铁 | 大杯 | 2 份 SOE | — | — |
| 摩卡咖啡 | 全杯型 | 2 份 | — | 约 60 ml |
| 绿野仙踪（特调） | 全杯型 | 2 份 | — | 约 60 ml |

**关键事实**：

- **常规美式不存在“单份浓缩”**：无论大杯还是超大杯，均为双份浓缩，差异在“加水量”。
- **拿铁是唯一按杯型递增浓缩份数的经典品类**：小 1 / 大 2 / 超大 3。
- **免费加浓选项**：小杯拿铁 / 澳白、冰椰美式、超大杯美式可免费加浓；其他加浓通常 +3 元。
- **燕麦奶 / 植物奶外卖拿铁**：1.5 份浓缩（部分门店规则）。
- 单份浓缩参考量：粉量 18–20 g，水温 92–94°C，萃取 25–30 秒；双份：粉量 25 g，萃取 ≤ 36 秒（更严格）。

## 3. 咖啡豆

### 3.1 默认拼配豆：MANNER BLEND

- **名称**：MANNER BLEND（亦称“Manner 小法棍意式拼配”）
- **拼配 / 产地**：四产地阿拉比卡拼配——
  - 埃塞俄比亚 耶加雪菲（水洗，提供明亮果酸）
  - 印度尼西亚 曼特宁（醇厚苦香）
  - 危地马拉（坚果调性）
  - 中国 云南（平衡感）
- **品种**：100% 阿拉比卡（Coffea arabica）
- **处理方式**：水洗（耶加雪菲为水洗耶加雪菲）
- **烘焙度**：**深烘**（门店用豆亦称“中深烘”，实际烘焙偏深以适配意式浓缩基底）
- **风味描述**：黑巧克力、榛果、奶油、烤坚果、焦糖
- **专利 / 自有**：Manner 自有配方、自家烘焙（上海茵赫实业运营）

### 3.2 SOE（Single Origin Espresso · 单一产地浓缩）

- **使用方式**：Manner 菜单中 **SOE 系列独立于默认拼配**，按周轮换产地
- **常见产地**：埃塞俄比亚（耶加雪菲、花魁、孔加）、卢旺达（厌氧日晒）、哥斯达黎加（塔拉珠）、云南、哥伦比亚、巴西等
- **烘焙度**：以 **中浅 / 中度烘焙** 为主，用于突出花香、果酸类单一产地风味
- **典型 SOE 产品**：SOE 拿铁（卢旺达厌氧日晒、埃塞白桃茉莉、埃塞凤梨甜橙、埃塞蜜瓜佛手柑、埃塞草莓茉莉、黄油榛果、芒果乌龙茶等）、SOE 美式、手冲（部分门店限定）、冷萃（每日更换豆子）
- **价格调整**：2026-04-07 起 SOE 单品豆咖啡饮品全线上调 5 元 / 杯（调价后约 25–30 元区间）；官方称因“选用品质更优的咖啡豆”

### 3.3 新鲜度承诺

- 选用 **烘焙好 20 天以内** 的咖啡豆
- 小批量烘焙，每批次严格质量检测

## 4. 奶源供应商

| 项目 | 内容 |
| :--- | :--- |
| **默认牛奶品牌** | 朝日唯品 |
| **供应商** | 山东绿源唯品乳业有限公司（运营品牌 “朝日唯品”） |
| **隶属** | 新希望乳业（新乳业）旗下子品牌 —— 2017 年新希望集团全资收购朝日唯品 |
| **奶源基地** | 山东莱阳 —— 自营有机农 + 牧场（1500 亩循环农作园区） |
| **类型** | 低温鲜奶（ESL 锁鲜技术），全程 2–6°C 冷链 |
| **产品线** | “咖啡专享牛乳”（针对咖啡场景优化）、有机牛乳、浓厚纯牛乳、娟姗牛乳等 |
| **进口 / 国产** | **国产**（中日在华合资历史 → 现中资） |
| **合作起点** | 2015 年 Manner 上海南阳路首店开业起即使用朝日唯品（行业普遍说法） |

**关键事实**：

- Manner 官方选奶逻辑（朝日唯品主理人公开发言）：**“不会抢咖啡的风味，也符合中国人喜欢牛奶带一丝丝甜味的口味”**。
- “自带杯减 5 元”优惠是 Manner 标志性营销，奶源成本支撑了“高品质 + 平价”定位。
- 部分门店在季节限定（如 Dirty 系列）使用 **明治纯牛奶 + 厚乳** 等其他乳源——但常规经典意式默认朝日唯品。

## 5. 默认温度

| 品类 | 默认温度 | 备注 |
| :--- | :--- | :--- |
| 热拿铁 / 热澳白 / 热拿铁类 | 约 **50–60°C**（奶温控制） | 网友与第三方测评普遍反馈：Manner 热饮属“温奶级”，不像瑞幸全自动机的“烫嘴型” |
| 热美式 | 出品温度偏低（冲水稀释） | 用户反馈“温热”；可选“少水 / 半水”提升浓度 |
| 冰美式 / 冰拿铁 | 默认 **正常冰** | 干姜美式、冰葡美式、冰橙美式 **不可完全去冰**，但可少冰；“去冰”会改为温热直饮水版本 |
| SOE / Dirty 系列 | 仅冰 / 仅热按 SKU 区分 | Dirty 需到店制作、外卖不可点 |

**关于温度的注意点**：

- Manner 出品温度较瑞幸“温和”，与精品咖啡强调“避免过烫破坏奶泡 / 焦化蛋白质”理念一致；与瑞幸全自动机“高效率出品、统一高温”形成明显差异。
- 行业内不公开的“出品温度标准”，以上为公开来源整理；Manner 官方小程序未标注具体温度数值。

## 6. 特殊工艺 / 风味修饰

### 6.1 设备：意大利 La Marzocco 半自动咖啡机

- **品牌**：La Marzocco（业内俗称“辣妈”）
- **主力型号**：Linea PB 双头（部分门店早期使用 GS3）
- **设备投入**：单店 8–18 万元 / 台（半自动机型）
- **Manner 立场**：从 2015 年首店至今 **坚持使用半自动**，区别于瑞幸 / 库迪的“全自动咖啡机 + 按键师”模式
- **机器特性**：双锅炉、饱和冲煮头、PID 控温；咖啡师可手动控制预浸泡、水温、压力曲线等所有萃取参数
- **取舍代价**：高度依赖人员技能、培训周期长、多门店标准化困难、高峰出杯速度受限于人手

### 6.2 萃取参数（双份浓缩标准）

| 参数 | 数值 |
| :--- | :--- |
| 粉量（双份） | **25 g**（高于行业平均；Manner 自家定义） |
| 水温 | 92–94°C |
| 萃取时间 | ≤ 36 秒 |
| 液重 | 粉量的 1.5–2 倍（约 36–50 g 浓缩液） |
| Crema | 榛果色、油脂丰富（深烘拼配特性） |

### 6.3 其他风味修饰

- **小法棍意式拼配**：店内 / 零售同名款拼配豆，深烘，油脂厚重，强调“黑巧克力、榛果、奶油”
- **季节限定**：周更 SOE、联名风味拿铁（保时捷、LV、野兽派、乌镇戏剧节、赫莲娜、祖·玛珑、浦东美术馆、草间弥生等）
- **Dirty 系列**：到店限定，使用明治纯牛奶 + 厚乳 + 浓缩分层呈现（夏威夷果 Dirty、淡黄油 Dirty 等）
- **自带杯政策**：自带非一次性杯减 5 元（2015 年延续至今）；自带杯需符合 PP ≥ 5 环保标准

### 6.4 门店类型差异（直营 / 加盟 / 外带档口）

- **全部为直营**：Manner 在中国市场 **无加盟店**，全国 2000+ 家门店均为上海茵赫实业有限公司直营（2026-04 报道数据：全国 2000+ 家）
- **门店形态**：早期为“2 平米街边小店”，后迭代为 20–50 平米主力店；近两年推出“轻食店”（MANNER CAFE，2021 年上海环球金融中心首店）、带面包工坊的旗舰店等
- **外卖**：2022 年与美团合作推出外卖业务（冰饮圆形滤纸、热饮无滤纸；不可单独点一杯冰块）
- **出杯差异**：精品店 / 旗舰店出品标准更稳定；小店高峰出杯速度较慢（界面新闻测算：单店日 250 杯 / 1 人 → 2.4 分钟 / 杯，与瑞幸全自动有明显效率差）
