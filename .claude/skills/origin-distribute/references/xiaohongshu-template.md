# 小红书 v1 分发模板

> 来源：`content/drinkzen/operation-plan/index.md` + `coconut-latte/index.md`（Day 1 样例）。
> 本文件是生成规则，**不是**生成结果本身。

---

## 章节结构

### 1. 标题

**长度**：≤ 22 字（小红书标题两行内显示完整）

**公式**（4 选 1，参考 `title-formulas.md`）：

| 类型 | 适用 origin | 触发关键词 |
| --- | --- | --- |
| 续命型 | 任何饮品 | 「续命」「抗饿」「加班」 |
| 数据型 | 含热量/糖/评级数据 | 「糖 Xg」「B 级」「热量 X」 |
| 场景型 | 通勤/学习/周末 | 「早八」「午后」「周末」 |
| 限定型 | 含日期/门店/品牌事件 | 「限定」「回归」「首发」 |

**禁忌**：

- 不用「减肥」「瘦」「低卡」等敏感词
- 不用夸张符号（震惊！、🔥🔥🔥）—— 平台会降权
- 不用第一人称数字（「我瘦了 5 斤」）—— 没有 origin 数据

### 2. 正文

**结构**（4 行模板，逐行匹配 origin 字段）：

```html
今日饮品：<品牌>·<产品名>（<杯型> <容量>ml）
<核心数据 1> | <核心数据 2> | <ABCD 评级>
DrinkZen 评级：<等级>（<触发维度>）
一句话：<origin 中的一句话评价，原文引用>
```

**长度硬约束**：≤ 80 字（小红书首屏 3 行内）。超长即压缩，**禁止扩写**。

**数据忠实度**：

- 热量：取 origin `## 产品速览` 的标注值
- 糖：取 origin 营养计算的「非乳源性糖」值
- 评级：取 origin 标注的 ABCD 等级
- 一句话：origin 中「一句话」原句或 `## 口感体验` 末段

### 3. 图片清单

**4-6 张**（4 张底线，6 张封顶），按 origin `gallery/` 目录顺序映射：

| 模板位 | 来源 | 角色 |
| --- | --- | --- |
| 图 1 封面 | origin 首图 | 封面杀手（决定打开率） |
| 图 2 杯身 | origin 杯身图 | 品牌识别 |
| 图 3 配料 | origin 配料表截图 | 信任锚点 |
| 图 4 DrinkZen 评估 | origin 评估表/小程序截图 | 数据可视化 |
| 图 5 场景（选） | origin 场景图 | 情绪锚点 |
| 图 6 结尾（选） | origin 结尾图 | CTA 引导 |

**图片处理禁忌**：

- 不重压画质（参见项目规则：不修改 origin 图片）
- 不裁剪 logo / 容量标识
- 不用动图（webp/live photo）—— origin carousel 已筛过

**封面文字叠加**（图 1 必备）：

- 左上角：品牌 Logo（直接复用 origin 图）
- 居中：产品名 + ABCD 评级
- 右下角：1 个数字钩子（如「160kcal」「糖 7g」）

### 4. 标签

**三档**（共 8-10 个）：

```text
# 必带 3：#奶茶仙人 #DrinkZen #南京饮品
# 栏目 2：#每日打卡 / #饮品测评
# 流量 3-5：#南京美食 #南京探店 #南京周末去哪儿 #新街口
```

**变量替换规则**：

- 必带 3 中 `#南京饮品` 在 origin 城市非南京时改为对应城市（如 `#杭州饮品`）
- 流量词按门店所在区/商圈调整
- 限定首发：加 `#首发` / `#限定回归`（不超过 1 个，避免刷屏感）

### 5. 评论区置顶

发布后**立即**置顶第一条评论（核心引流动作）：

```html
🥤 DrinkZen 小程序搜「<产品名>」，看完整评估
📍 门店：<区/路 + 品牌>（origin 中有则用，无则「待补」）
💡 推荐点单：<冰度> / <糖度> / <杯型>
```

**门店缺失处理**：origin 没有门店时，置顶用「待补」+ 备注「发布前手动补充」。
