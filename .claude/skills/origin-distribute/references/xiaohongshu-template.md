- 字数：v1 ≤80 字 → v2 主流 400-550 字 → **v2.1 主流 500-600 字**（信息密度上限）

## 章节结构

### 1. 标题

**长度**：≤ 20 字（小红书标题两行内显示完整）

**v2 公式**：`<卡路里>大卡 <评级> <风味钩子>`

| 模板 | 适用 origin |
| --- | --- |
| `431大卡 D 级警告，咸甜脆三重小心机` | 含 D 级 + 三重口感卖点 |
| `292大卡 C 级抹茶清新，液体奶酪咸香` | 含 C 级 + 抹茶/液体奶酪风味 |
| `197大卡 C 级桂米咖，三层香气递进` | 含 C 级 + 多层香气卖点 |

**v2 规则**：

- **禁止** 使用 `|` 分隔符（v1 风格，平台降权 + 阅读节奏差）
- **卡路里必须前置**（开头 ≤ 6 字内出现 `<数字>大卡`）
- **评级紧跟**（D 级 / C 级 / B 级 / A 级）
- **风味钩子**用抽象词（咸甜脆、清新、咸香、三层递进），避免直接点出产品全名
- 数字 / 字母 / 中文 / 全角标点 均按 1 字计，**空格不计**

**禁忌**：

- 不用 `|` `🔥🔥🔥` `震惊` `家人们` `姐妹们`
- 不用 `减肥` `瘦身` `掉秤` 等敏感词
- 不用第一人称数字（「我瘦了 5 斤」）—— 没有 origin 数据

---

### 2. 正文（6 段统一结构）

**字数**：500-600 字（v2 主流 400-550 字 → v2.1 提升信息密度上限）

**头部信息**（必含，3-5 行）：

```text
📍 今日饮品：<品牌>·<产品名>（大杯 <容量>ml，超大杯 <容量>ml）
🔖 默认配置：<温度> / <糖度>（<配置约束>）
📅 上市：<日期>（<范围>，<同日上新其他产品>）
🎯 所属系列：<系列名>（<系列核心卖点>）
[<联名> / <酒精警告> / <关键限制> 等]
```

**6 段结构**（每篇必含，顺序固定）：

#### 【1】营养参数 ⚠️ <口径>

**必含元素**：

- 热量（大杯为主，⚠️ 标注计算口径或官方口径）
- **超大杯警告**（超大杯热量 / 评级直接冲到 D 级的情况）
- 糖（总糖 + 非乳源性糖分别披露）
- 蛋白质 / 脂肪 / 饱和脂肪
- 咖啡因 + **来源说明**（单源 / 双源）
- 杯量 + 冰块占比
- **过敏原具体到原料**（不是"含乳"而是"含液体奶酪 + 海盐芝士奶盖"）

**来源**：origin `## 产品速览` + `## 配方营养计算`

#### 【2】热量评级：<等级>

**必含元素**：

- 饱和脂肪 g/100ml + 等级
- 非乳源性糖 g/100ml + 等级
- 取较差项 → 最终等级
- **克重数据**：唯一降级方式的具体克重（如"液体奶酪 + 海盐芝士奶盖同时减半，克重降到 15g + 5g"）
- **热版对比**：热版饱和脂肪冲到多少（如果 origin 有数据）
- **vs 同系列对比**：与同系列其他产品的等级差异（如"比抹茶奶酪拿铁高一档"）

**来源**：origin `## Nutri-Grade 评级` + `## 参数叠加汇总`

#### 【3】制作配方 · N 层叠加

**必含元素**：

- **完整 N 层原料清单**（含最后一步，如加碘海盐）
- 每个原料的克重 / 毫升
- 关键工艺说明（千目级 / 双窨制 / IIAC 金奖 / 1:8 打发等）
- **制作流程箭头链**（杯底→步骤1→步骤2→...→顶部，每一步都不能漏）

**来源**：origin `## 制作方式调查` + `## 配方营养计算`

#### 【4】饮品特色

**必含元素**：

- **认证背书**（IIAC 金奖 / WBC 推荐 / 国家地理标志产品等）
- **vs 同系列差异化**（双源叠加 vs 单液体奶酪 / 唯一带坚果颗粒等）
- 工艺亮点（深度烘焙 / 短萃浓缩 / 千目级等）
- 风味关键词

**来源**：origin `## 产品速览` + `## 口感体验` 的"工艺特点"段落

#### 【5】口感体验

**必含元素**：

- **前调 / 中段 / 中下段 / 尾调** 四个层次（**不能合并**）
- **混合后**的状态
- **冰版 vs 热版对比**（如果 origin 提及，必须显式写出）
- vs 同系列其他产品的口感差异（如"咖啡本味比抹茶奶酪拿铁更明显"）

**来源**：origin `## 口感体验` 的"风味层次"段落

#### 【6】健康建议 ⚠️

**必含元素**：

- 过敏原（**具体到原料名称**）
- 乳糖不耐受 / 特殊人群（驾驶员 / 孕妇 / 酒精过敏者 / 控脂 / 控糖）
- **饮用方式**（先尝 / 搅拌 / 顺序，origin `## 饮用建议` 的"饮用方式"）
- **杯型警告**（超大杯冲到 D 级时必须明示）
- **进阶对比**（origin `## 饮用建议` 的"进阶对比"段落，4 个左右）

**来源**：origin `## 饮用建议` + `## 数据说明`

**变量替换规则**：

### 5. 评论区置顶

发布后**立即**置顶第一条评论（核心引流动作）：

```html
🥤 DrinkZen 小程序搜「<产品名>」，看完整评估
📍 门店：<区/路 + 品牌>（origin 中有则用，无则「待补」）
💡 推荐点单：<冰度> / <糖度> / <杯型>
```

**v2.1 扩展规则**：

- 涉及过敏原 / 酒精 / 控糖 / 控脂时，必须额外加 1-2 行警告
- 涉及唯一降级方式时，加 1 行操作提示（**含克重数据**）
- 涉及联名时，加 1 行周边清单
- 涉及杯型警告时（超大杯冲到 D 级），加 1 行警告
- 涉及系列时，加 1 行同日上新产品

**门店缺失处理**：origin 没有门店时，置顶用「待补」+ 备注「发布前手动补充」。

## 横向对比触发条件（v2.1 新增）

## 警告触发条件（v2.1 新增）

| 触发条件 | 警告内容 | 必含位置 |
