# DrinkZen - 饮品品牌与饮品页面创建技能

## 概述

DrinkZen 是一个用于创建和维护饮品品牌页面及饮品详情页面的技能。支持的目录结构为 `content/drinkzen/<brand>/`，每个品牌有一个 `_index.md` 品牌页，每款饮品有一个 `<drink-name>/index.md` 详情页。

## 工作流程

### 1. 创建新品牌页面

当用户要求创建新品牌的页面时：

1. 在 `content/drinkzen/` 下创建品牌目录
2. 创建 `_index.md` 品牌页，使用品牌页模板
3. 搜索品牌信息，填充品牌简介、产品系列、热量数据等

### 2. 创建饮品页面

当用户要求创建某品牌的具体饮品页面时：

1. 搜索该饮品的配方、热量、价格等信息
2. 在品牌目录下创建 `<饮品名拼音>/index.md`
3. 使用饮品页模板填充内容

### 3. 批量创建

当用户要求批量创建饮品页面时：

1. 先搜索该品牌的完整菜单
2. 规划需要创建的饮品列表
3. 使用 Agent 并行创建多个饮品页面（建议每批 10-15 款）
4. 更新品牌页的产品列表

## 健康评级引用规范

### 评级标准存放位置

评级标准的详细介绍统一放在 `content/drinkzen/nutri-grade/index.md`，包含：

- 新加坡 Nutri-Grade 评级体系（A-D 级）
- 中国上海「营养选择」评级体系（A-D 级）
- 两大体系的对比说明

### 品牌页引用方式

品牌页中简要说明该品牌使用的评级体系，并链接到统一页面：

```markdown
## 健康评级

<品牌名>采用**<评级体系名称>**，由<制定机构>制定。

**评级规则**：<简要说明规则，1-2 句>

> 💡 评级体系详解见「[饮品健康评级：新加坡 ABCD 与中国上海标准](/drinkzen/nutri-grade/)」
```

### 饮品页引用方式

饮品页中只标注评级结果，不重复介绍标准。在两个位置体现：

1. **产品速览**：直接标注评级

```markdown
- **健康评级**：A 级（不另外加糖）/ B 级（标准糖）
```

2. **数据说明**：简单链接

```markdown
- **评级标准**：<体系名称>（详见 [评级说明](/drinkzen/nutri-grade/)）
```

### 避免的冗余写法

❌ 不要在饮品页中重复以下内容：

```markdown
## 营养选择评级

<品牌名>采用**<评级体系>**，由<制定机构>制定。

**评级规则**：<完整规则说明>

**某饮品示例**：
- 不另外加糖：B 级
- 标准糖：C 级

> 💡 评级体系详解见「[饮品健康评级](/drinkzen/nutri-grade/)」
```

✅ 应该简化为：

```markdown
- **健康评级**：B 级（不另外加糖）/ C 级（标准糖）
```

```markdown
- **评级标准**：<体系名称>（详见 [评级说明](/drinkzen/nutri-grade/)）
```

## 搜索信息指南

创建饮品页面前，需要搜索以下信息：

### 搜索关键词

1. **品牌菜单**：`<品牌名> 菜单 饮品列表`
2. **饮品热量**：`<品牌名> <饮品名> 热量`
3. **饮品配方**：`<品牌名> <饮品名> 配料 原料`
4. **消费者评价**：`<品牌名> <饮品名> 口感 评价`

### 信息优先级

1. **一级数据源**（可信度最高）：品牌官网、官方小程序、产品身份证
2. **二级数据源**（参考价值）：第三方实测、消费者评价、媒体报道

## 目录命名规范

饮品目录名使用拼音，规则如下：

- 全小写
- 多个词用 `-` 分隔
- 去掉声调符号
- 示例：
  - 红茶玛奇朵 → `hong-cha-ma-qi-duo`
  - 冰鲜柠檬水 → `bing-xian-ning-meng-shui`
  - 多肉葡萄 → `duo-rou-putao`

## 并行创建策略

当需要批量创建饮品页面时：

1. 先完成品牌页创建
2. 按系列分组，每组 10-15 款饮品
3. 使用 Agent 并行创建，每个 Agent 负责一个系列
4. 创建完成后验证文件数量
5. 更新品牌页的产品列表
6. 提交 git
