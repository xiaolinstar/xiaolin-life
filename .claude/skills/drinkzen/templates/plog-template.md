# plog 模板 v2

> 小红书 / 大众点评通用一份模板（5 段结构 + Origin 抽取 + 通用铁律 + 完整样例）。
> 源自小红书 v2.3 模板（秋桂米酿拿铁复盘升级）+ operation-plan 大众点评同步需求。
> 维护者：运营 + Claude；规则冲突时优先小红书铁律（更长更精细）。

## v2 关键变化

- **撤销平台差异化**：小红书与大众点评共用同一份 plog（5 段结构）+ 同一标题公式 + 同一标签
- **删除 plog 短版**：之前 v1 的"大众点评 ≤30 字"评价型短版作废，改为同一份长版通用
- **新增「完整样例」**：基于 Manner 拿铁 C 级演示成品，标题 / 正文 / 标签 / 评论区置顶一一对应
- **新增「emoji 使用规范」**：鼓励 🥤 / 📍 / 💡 / 🔔 四件套；禁止 ⚠️ / 感叹号 / 表情堆叠 / 装饰 emoji
- **新增「换行与分段规范」**：段间空行 / 段内换行 / 数据独立成行等具体规则
- ⚠️ 警告触发符号统一改用 🔔（与 [drinkzen-no-warning-triangle 记忆](~/.claude/projects/.../memory/drinkzen-no-warning-triangle.md) 一致）

## 平台使用说明

- **小红书**：标题 + 正文（5 段）+ 标签 + 评论区置顶（必发）
- **大众点评**：标题 + 正文（5 段）+ 标签；评论区置顶可选
- **同一份 plog 内容** 在两个平台复用，按平台规范微调标签或删减评论区置顶即可

## 标题公式（小红书 / 大众点评共用）

数据型公式（v2 主推）：`<卡路里>大卡 <评级> <风味钩子>`

- **信息密度**：卡路里 + 评级 + 风味钩子
- **结构**：`<卡路里>大卡 <评级> <风味钩子>`
- **硬上限**：20 字

## plog 长版（小红书，≤ 800 字）

### 5 段结构（连续编号【1】→【5】，无缺口）

#### 【1】营养参数

必含：热量（含口径）+ 糖（总糖 + 非乳源性糖）+ 蛋白质 / 脂肪 / 饱和脂肪 + 咖啡因（含来源：单源/双源）+ 杯量 + 冰块占比。

#### 【2】热量评级

必含：饱和脂肪 g/100ml + 等级 + 非乳源性糖 g/100ml + 等级 + 取较差项 → 最终等级 + 克重数据（唯一降级方式）+ 热版对比（如有）+ 同系列对比（如有）。

#### 【3】制作配方 · N 层叠加

必含：完整 N 层原料清单（含最后一步）+ 每原料克重/毫升 + 关键工艺说明（千目级/双窨制/IIAC 金奖/1:8 打发等）+ 制作流程箭头链（杯底→步骤1→…→顶部）。

#### 【4】口感体验

必含：连贯主观体验（开盖→第一口→中段→尾调）+ 关键感官对比（冰 vs 热）。

#### 【5】健康建议

必含：特殊人群（驾驶员/孕妇/控脂/控糖/乳糖不耐受/胃酸过多等）+ 控糖说明（最低糖度限制 / 唯一降级方式）。

## 完整样例（Manner 拿铁 · C 级 · 大杯 355ml 冰）

### 正文（小红书 / 大众点评共用）

```text
158大卡 C 级奶咖，奶香饱满带甘

【1】营养参数
Manner 拿铁大杯 355ml 冰
实际液体 295ml（双份浓缩 60ml + 朝日唯品全脂奶 235ml）冰块 120ml
🔥 热量 178kcal
💪 蛋白 9.7g
🍬 总糖 11.3g（乳糖 11.3g）🚫 非乳源性糖 0g
🥑 脂肪 9.6g ⚡ 饱和脂肪 5.3g
☕ 咖啡因 186mg（双份浓缩）

【2】热量评级 C 级
饱和脂肪 1.7g/100ml 触级 非乳源性糖 0g 落 A 取较差 C
最低糖度不另外加糖已无法降至 B 级 因饱和脂肪不受加糖影响
热版对比 大杯热 355ml 51kcal/100ml 同样 C
同系列对比 SOE 拿铁 B-C 燕麦拿铁 B-C 标准款因全脂奶饱和脂肪浓度稍高 落 C

【3】制作配方 · 4 层叠加
① 朝日唯品有机全脂奶 235ml（山东莱阳 循环农作 3.8g 蛋白/100ml 低温巴氏）
② 冰块 120ml
③ Manner 拼配豆双份浓缩 60ml
④ 杯底先放冰 加奶 倒浓缩

【4】口感体验
开盖先闻到朝日唯品的有机奶香，自然甘甜。第一口奶感饱满，浓缩苦味被全脂奶裹住。中段奶香与咖啡醇厚交织，尾调咖啡回甘。相比 SOE 拿铁，奶感更扎实但少了产地辨识

【5】健康建议
驾驶员孕妇可饮，咖啡因 150mg 安全。控脂注意，饱和脂肪 5.0g 触 C，控糖友好，默认无糖。乳糖不耐受不建议，朝日唯品含乳糖 11.3g 可换燕麦奶。唯一降级：换燕麦奶，降脂降热量
```

### 评论区置顶（小红书必发，大众点评可选）

```text
🥤 DrinkZen 小程序搜「Manner 拿铁」，看完整评估
📍 门店：南京 / Manner（待补具体门店）
💡 推荐点单：大杯冰 / 不另外加糖 / 全脂奶
💡 低脂替代：小程序不支持脱脂奶，可换燕麦奶
💡 控糖期注意：最低糖度仍触 C 级（饱和脂肪 5.0g）
```

### 禁止使用

| emoji | 原因 |
| :--- | :--- |
| ⚠️ | 视觉硬；用户偏好已确认改用纯文字 / 🔔 替代 |
| ！/ ! | 平台降权（小红书）+ 标题铁律禁 |
| 🔥🔥🔥 | 表情堆叠触发审核 |
| 💖✨🌟 等装饰 | 油腻、AI 感强 |
| 第一人称数字 emoji | origin 无数据 |

### 使用原则

- 评论区置顶 🥤 / 📍 / 💡 / 🔔 四件套为主
- plog 正文 ≤ 2 个 emoji / 段
- 警告场景用 🔔 替代 ⚠️
- 不用 emoji 替代文字（emoji 后必跟文字内容）

## 换行与分段规范

### plog 正文（≤ 800 字）

- **结构化段**（【1】【2】【3】）：保留换行
  - 【1】营养参数：每行 1-2 个数据点，关键指标 emoji 装饰
  - 【2】热量评级：每行一项（饱和脂肪 / 糖 / 取较差 / 降级路径 / 热版对比 / 同系列对比）
  - 【3】制作配方：每行一层原料 + 工艺 + 流程箭头
- **叙述段**（【4】【5】）：合并为 1-2 段自然文字
  - 【4】口感体验：连贯一段（开盖→第一口→中段→尾调→对比）
  - 【5】健康建议：合并为 1-2 段（特殊人群 + 控糖 / 控脂 / 乳糖 / 降级路径）
- 5 段连续编号【1】→【5】，**段间空一行**

**反面教材**（段内逗号堆叠）：

> 热量 158kcal, 总糖 11.3g, 蛋白 9.2g, 脂肪 8.6g, 饱和脂肪 5.0g, 咖啡因 150mg, 双份浓缩, 朝日唯品, 山东莱阳

**正面教材**（每行一个数据点）：

> 热量 158kcal
> 总糖 11.3g（乳糖 11.3g）
> 非乳源性糖 0g
> 蛋白 9.2g
> 脂肪 8.6g
> 饱和脂肪 5.0g
> ☕ 咖啡因 150mg（双份浓缩）

**折中方案**（行内空间有限时，邻近数据同行）：

> 热量 158kcal 总糖 11.3g（乳糖 11.3g）非乳源性糖 0g 蛋白 9.2g 脂肪 8.6g 饱和脂肪 5.0g ☕ 咖啡因 150mg（双份浓缩）

### 大众点评短版（30 字）

- 每行 5-10 字
- 段间无空行（短文本紧密）
- 标签段单行罗列

## 通用铁律（两平台共享）

| 铁律 | 说明 |
| :--- | :--- |
| 无内部链接 | 禁止 `[text](/drinkzen/...)` `[text](url)` 等 |
| 无感叹号 | 禁止 `！` `!`（含半角全角） |
| 无 markdown 列表 | 禁止 `-` `*` `+` `1.` `1.` 开头 |
| 无 markdown 加粗 | 禁止 `**text**` |
| 无博主实测 | origin 中的"博主实测"默认不进入 plog（除非有官方背书） |
| 段落尾部无句号 | 每段最后一句结尾不写句号（段中分句句号保留） |
| 不补卖点 | origin 没写的卖点禁止凭空添加 |

**判断原则**：plog 是直接粘贴发布的纯文本。所有站点内部链接 / 标记语法粘过去都会变成字面字符。**粘到平台是否会变成字面字符 / AI 生成感是否强烈** 是核心判断。

| 字段 | origin 位置 | 必含原因 |

| 同日上新产品 | `## 产品速览` 系列段 | 系列上下文 |
| 所属系列 | `## 产品速览` | 横向对比锚点 |
| 默认配置 | `## 产品速览` | 头部信息必含 |
| Nutri-Grade 评级 | `## 产品速览` + `## Nutri-Grade 评级` | 标题 + 评级段 |
| 热量（含口径） | `## 产品速览` + 营养表 | 标题 + 营养段 |
| 咖啡因 + 来源 | `## 产品速览` | 营养段 |
| 工艺认证 | `## 产品速览` + `## 制作方式调查` | 制作配方 / 口感体验段 |

| 标签词 | frontmatter `tags` | 标签段 |

## 标签三档（8-10 个）

```text
# 必带 2-3：#奶茶仙人 #DrinkZen [可选 #城市饮品]
# 栏目 2：#每日打卡 / #饮品测评
# 流量 3-5：城市相关 + 通用流量 mix
```

**变量替换规则**（v2.3 升级，2026-10-06）：

- **必带 2-3**：`#奶茶仙人` + `#DrinkZen` 必带；`#南京饮品` 等城市 tag **仅限南京本地饮品**
- **全国连锁饮品**：只用必带 2，不加城市 tag
- **流量词**：南京本地 → `#南京美食 #南京探店 #新街口`；全国连锁 → `#饮品分享 #今日打卡 #咖啡日常`
- **限定首发**：加 `#首发` / `#限定回归`（不超过 1 个）

## 评论区置顶（小红书）

发布后立即置顶第一条评论：

```text
🥤 DrinkZen 小程序搜「<产品名>」，看完整评估
📍 门店：<区/路 + 品牌>（origin 中有则用，无则「待补」）
💡 推荐点单：<冰度> / <糖度> / <杯型>
```

涉及过敏原 / 酒精 / 杯型时，加 `🔔 <警告内容>` 行（替代 v1 的 ⚠️）。

## 自检 checklist（生成 plog 后逐项核对）

- [ ] 标题 ≤ 20 字，无 `|`，无感叹号，无敏感词（减肥/瘦身/掉秤）
- [ ] plog 长版 ≤ 800 字（红线 1000）
- [ ] plog 长版 5 段连续编号【1】→【5】，无缺口
- [ ] plog 长版无 markdown 内部链接 / 感叹号 / 列表符号 / 加粗
- [ ] plog 短版 ≤ 30 字，含"味道 + 服务 + 一句感受"
- [ ] 标签 8-10 个，三档齐全
- [ ] 所有数字与 origin 完全一致
- [ ] 评论区置顶 3-7 行，含核心引流
- [ ] 警告条件已触发（参见 [警告触发条件]）

### 警告触发条件

| 触发条件 | 警告内容 | 必含位置 |
| :--- | :--- | :--- |
| D 级评级 | "D 级警告 / 控脂慎点" | 标题 + 【2】 + 评论区 |
| 含米酒 / 含醇 | "驾驶员 / 孕妇禁点" | 头部 + 【5】 + 评论区 |
| 控糖期无法降到 B 级 | "最低糖度已无法降级" | 【2】 + 【5】 |
| 没有"不另外加糖"选项 | "最低糖度就是微甜" | 头部 + 评论区 |
