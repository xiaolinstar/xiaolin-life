# DrinkZen 搜索指南

## 搜索策略

### 品牌信息搜索

搜索品牌基本信息时，使用以下关键词组合：

| 信息类型 | 搜索关键词示例 |
| :--- | :--- |
| 品牌简介 | `<品牌名> 品牌介绍 创始人 门店数量` |
| 完整菜单 | `<品牌名> 菜单 饮品列表 完整` |
| 热量数据 | `<品牌名> 热量表 卡路里 营养成分` |
| 小料价格 | `<品牌名> 小料 配料 价格` |

### 饮品信息搜索

搜索具体饮品信息时：

| 信息类型 | 搜索关键词示例 |
| :--- | :--- |
| 配方原料 | `<品牌名> <饮品名> 配料 原料 配方` |
| 热量数据 | `<品牌名> <饮品名> 热量 卡路里` |
| 口感评价 | `<品牌名> <饮品名> 口感 评价 好喝` |
| 点单攻略 | `<品牌名> <饮品名> 点单 攻略 推荐` |

## 数据源优先级

### 一级数据源（可信度最高）

1. 品牌官网（如 alittle-tea.com、heytea.com）
2. 官方小程序/App（热量计算器、产品身份证）
3. 官方公众号（配方公开、检测报告）

### 二级数据源（参考价值）

1. 第三方实测数据（什么值得买、小红书测评）
2. 消费者评价（大众点评、美团评价）
3. 媒体报道（今日头条、网易新闻）

### 三级数据源（需验证）

1. 个人博客、微博
2. 未经证实的网络信息

## 热量数据说明

### 数据格式

- 热量单位：kcal（千卡）
- 标注格式：`约 XXXkcal（杯型/糖度）`
- 示例：`约 250kcal（中杯/三分糖）`

### 数据来源标注

- ✅ 官方数据：来自品牌官方渠道
- ⚠️ 估算数据：基于配方计算或第三方实测
- ❓ 参考数据：来源不明，仅供参考

## 常用搜索工具

1. **WebSearch**：用于搜索实时信息
2. **WebFetch**：用于获取特定网页内容

## 搜索结果处理

### 信息整合

1. 从多个来源交叉验证数据
2. 优先采用官方数据
3. 对于矛盾信息，以最新、最权威的来源为准

### 数据缺失处理

当搜索不到某项数据时：

1. 热量：根据配方估算，标注为"约 XXXkcal"
2. 价格：标注为"约 XX 元"
3. 口感：基于消费者评价总结
