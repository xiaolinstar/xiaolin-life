# DrinkZen 核心评级标准

## 两套标准与默认值

DrinkZen 仅采用新加坡 Nutri-Grade（默认，标识 `singapore`）和上海“营养选择”（可选，标识 `shanghai`）。上海结果只能明确标为上海评级，不改称 Nutri-Grade，也不与新加坡阈值混算。

热量、总脂肪和咖啡因单独展示，不组成第三套 ABCD。等级描述营养指标，不保证某杯饮品适合所有人。大陆饮品引用国外规则推算时注明“DrinkZen 按新加坡标准估算”，不冒充品牌官方标识或认证。

## 新加坡 Nutri-Grade

按每 100ml 的糖和饱和脂肪判级，取较差项；含非糖甜味剂时不能为 A。糖按总糖扣除有依据的乳糖、半乳糖，不能未经核实把水果糖全部豁免。

| 等级 | 计入评级的糖（g/100ml） | 饱和脂肪（g/100ml） |
| --- | --- | --- |
| A | ≤1 | ≤0.7 |
| B | >1 且 ≤5 | >0.7 且 ≤1.2 |
| C | >5 且 ≤10 | >1.2 且 ≤2.8 |
| D | >10 | >2.8 |

两列分别分级后取最差值，不能要求两列同时落入同一行。乳糖、半乳糖扣减须有营养依据；缺少依据不自动推为全乳糖。实际适用范围、取样和体积要求以 [HPB 官方指引](https://www.hpb.gov.sg/healthy-living/food-and-beverage/nutri-grade/) 为准，规则核对日期：2026-10-11。

## 上海“营养选择”

综合非乳源性糖、饱和脂肪、反式脂肪和非糖甜味剂，取最差项。采用 [上海疾控分级原图及说明](https://www.shhk.gov.cn/xwzx/002008/002008040/20240410/1748ceae-be22-4584-9957-1aa86d047df1.html) 对应版本，不复制新加坡表格代替上海标准；规则核对日期：2026-10-11。

有同一配置的品牌上海标识时可引用并保存证据。需要自行计算时，先读取原标准的完整阈值和边界条件，记录来源版本；未完成此核对或缺少四项必要输入时，上海评级保持待核实。不得用后来同名的其他地区标准静默替换上海标准。

## 每条评级的记录

至少保留标准名称、版本来源、饮品配置、每 100ml 口径、数据来源、判级依据、结果及“官方标识/检测数据推算/配方估算/待核实”状态。官方上海 B 级不能直接当成新加坡 B 级。

缺少有效体积、糖、饱和脂肪或甜味剂资料时，不补出确定新加坡评级；缺上海所需输入时同理。历史页尚未复核的字母等级不自动升格为已验证结果。
