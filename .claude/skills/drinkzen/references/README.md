# DrinkZen 社媒分发

小红书与大众点评发布同一份标题、正文、标签和配图素材。只保留一个 plog 正文 tab，不生成平台短版、专属草稿或重复文案。

## 生成

1. 读取 origin 的菜单、数据依据和作者体验；缺失处理见 [search-guide.md](search-guide.md)，评级见 [ratings.md](ratings.md)。
2. 使用 [plog-template.md](../templates/plog-template.md) 在 origin 末尾维护 `## plog 分发版`，含标题、正文、标签、引流评论和图片清单。
3. 同一份文案采用 [共用标题公式](title-formulas.md)。`platforms: [xiaohongshu, dianping]` 仅表示计划覆盖的平台，不表示已发布。
4. 图片从同一份 origin 素材清单准备；可用杯身、菜单、评估截图和场景图，不为凑张数虚构素材。营养/评级尚未核实时封面不展示确定等级。
5. 构建或本地预览核对 tab；标题、正文、封面与评论的配置和数字一致。

## 发布与记录

发布仍由用户在平台 APP 完成。复制同一份标题、正文和标签，使用同一素材清单；引流评论共用同一文本，平台是否支持置顶仅影响操作，不另生成一份内容。

发布后分别记录实际链接、时间、对应后台产品、菜单证据与内容版本。固定 11:30 可作为既有排期参考，不冒充经过效果验证的最佳时间。详细记录与更新规则见 [operations.md](operations.md)。

Origin 更新后重生成共用 plog，检查已发布的两个平台是否需要纠正；后台菜单变化也要回查 origin 和推荐点单。不假定修改站点会同步修改已发布笔记。
