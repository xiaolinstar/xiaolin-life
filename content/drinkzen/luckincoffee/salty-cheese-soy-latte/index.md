## 制作方式调查

**官方主要原料**（来源：瑞幸官方小程序饮品顶部说明）：

- **东北非转基因大豆豆乳**：饮品名「咸芝士豆乳拿铁」明确使用大豆豆乳（非燕麦/非椰子），强调东北产区 + 非转基因原料
- **鲜牛奶**：默认奶基为牛奶（小程序价格分项确认「+牛奶 ¥0」），与豆乳共同构成主体乳基
- **浓缩咖啡**：默认 30ml 单份（沿用品牌拿铁系列口径），豆基三选一
- **咸芝士奶盖**：顶部默认覆盖（小程序截图确认），含海盐 + 芝士风味
- **细腻黄豆粉**：顶部撒粉装饰（与「咸芝士」奶盖形成芝香 + 豆香双层香气）

> **三重风味结构**（瑞幸官方定位「一口三重风味」）

1. **顶部**：海盐芝士奶盖 + 细腻黄豆粉（咸鲜 + 芝香 + 豆香）
2. **主体**：东北非转基因大豆豆乳 × 鲜牛奶（豆香 + 奶香，豆乳中和牛奶的「腻」感）
3. **底部**：三豆基任选浓缩咖啡液（意式拼配坚果香 / 深烘拼配黑巧浓郁 / 埃塞金烘花香可可）

**SKU 结构**：

- 杯型：大杯 450ml / 超大杯 596ml（限量联名杯）
- 温度：冰 / 热（默认冰）
- 豆基：意式拼配（IIAC 金奖）/ 深烘拼配（咖啡更浓）/ 埃塞金烘（IIAC 铂金）（默认深烘拼配）

- 糖度：标准甜 4 泵 / 少甜 3 泵 / 少少甜 2 泵 / **微甜 1 泵（默认）** / 不另外加糖
- 奶盖：默认覆盖咸芝士奶盖

> **关于「微甜为默认」**：与同品牌多数饮品默认「不另外加糖」不同，本 SKU 默认配置为「微甜 1 泵」。可能原因：豆乳本身偏清淡 + 咸芝士奶盖偏咸鲜，需 1 泵糖浆平衡咸感与豆香，否则会出现「咸盖 + 淡豆乳 + 咖啡苦」的三段断层。

**推荐点单**：大杯 450ml / 冰 / 深烘拼配 / 默认浓度 / **微甜 1 泵**（默认）/ 牛奶 / 默认奶盖 → ¥21

> **热饮提醒**：去掉 185ml 冰块后，每 100ml 饱和脂肪由 0.9g 上升到 1.55g（C 级），强烈建议冰饮。

## 口感体验

入口咸芝士奶盖先到，海盐的咸鲜与芝士的奶香在舌尖铺开；中段是豆乳 + 牛奶的清甜豆香，豆乳中和了牛奶的「腻」感，让整杯比纯牛奶拿铁更轻盈；底部浓缩咖啡（深烘拼配）的黑巧尾韵在最后托住整杯。微甜 1 泵刚好平衡咸盖与豆香、咖啡苦。整体比瑞幸标准拿铁更柔、比抹茶奶酪拿铁更清。

## 饮用建议

- **最佳温度**：冰饮 4-8°C（咸芝士奶盖在冰镇下结构更稳定，热饮奶盖易化 + 每 100ml 浓度飙升到 C 级）
- **最佳豆基**：深烘拼配（默认，浓郁口感与豆乳 + 芝士形成「重芝香 + 浓郁咖啡」组合）；追求精品风味可选埃塞金烘（花香可可 + 豆乳清爽更搭）
- **最佳糖度**：微甜 1 泵（默认；社区平衡点；不另外加糖会让咸盖偏咸 + 豆香发寡，标准甜 4 泵则盖掉咖啡苦）
- **最佳饮用方式**：到手先尝顶部咸芝士奶盖 + 黄豆粉（咸鲜 + 豆香），再用吸管搅匀饮用主体
- **适宜场景**：秋冬季下午茶、办公室提神（咸鲜开胃）、控脂党下午替代（比抹茶奶酪 C 级更友好）
- **不建议**：
  - 热饮爱好者（饱和脂肪冲到 C 级）
  - 严格控糖者（即使不另外加糖，豆乳天然糖也卡在 B 级边界）
  - 对大豆 / 牛奶 / 芝士过敏者（三层乳制品叠加）
