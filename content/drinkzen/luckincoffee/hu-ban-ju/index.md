## 产品速览

瑞幸咖啡 · 虎斑橘 · 瑞幸特调（黄油丝绒奶盖版）

- **系列**：瑞幸特调系列（Special Drinks）
- **杯型**：特调杯 12oz（≈ 354ml，**固定杯型**，无中/大/超大杯选项）
- **温度**：冰（**固定冰饮**，无热饮选项）
- **Nutri-Grade**：**D 级**（无酒精 / 微微甜，估算值）⚠️
- **热量**：约 240 kcal（12oz / 微微甜 / 无酒精）⚠️
- **饱和脂肪**：约 2.82 g/100ml（临界 D 级阈值 2.8 g）
- **咖啡因**：182.2 mg ✅
- **蛋白质**：8.3 g/杯 ✅（官方参考值）
- **过敏原**：乳及乳制品
- **价格**：13.9 元/杯（含酒精版 +3 元）
- **特点**：黄油丝绒奶盖 × 现刨橙皮碎 × 耶加雪菲，虎纹分层直饮
- **命名由来**：灵感来自墨尔本网红特调「Tiger Bomb」——浓缩咖啡沿杯壁缓缓浇入冰牛奶形成虎纹分层，顶部撒现刨橙皮碎，「虎斑」由此得名

## 制作方式调查

**官方主要原料**（✅ 来源：瑞幸官网 lkcoffee.com）：

- 黄油丝绒风味奶（含新西兰进口无水黄油）
- 淡奶油
- 耶加雪菲咖啡液
- 门店现刨橙皮
- 焦糖味奶盖

**原料工艺**：

- 含新西兰进口无水黄油，奶盖丝绒醇厚
- 耶加雪菲精品咖啡豆，柑橘调性为整杯托起骨架
- 门店现场刨制橙皮碎，香气即时挥发
- 焦糖味奶盖提供甘甜与微焦香气

**SKU 选项**（杯型 / 温度固定，仅糖度与酒精可变）：

| 维度 | 可选项 |
| :--- | :--- |
| 杯型 | **12oz 特调杯**（固定，无其他杯型） |
| 温度 | **冰**（固定，无热饮） |
| 甜度 | 微微甜（默认） / 微甜 / 少少甜 |
| 鲜果 | 有鲜果 / 无鲜果 |
| 酒精 | 不含酒精（默认） / 含酒精（+3 元，部分门店供应） |

**推荐点单**：12oz / 冰 / 微微甜 / 无酒精（默认配置）

> **⚠️ 杯型 & 温度固定**：虎斑橘仅提供 12oz 特调杯与冰饮，不可选大杯、超大杯或热饮。这是与瑞幸常规咖啡产品的最大差异。

**官方推荐喝法**：**无需吸管、不用搅拌，开盖直接饮用**——保留虎纹分层与顶部橙皮香气层次。

**最佳赏味期**：15 分钟内喝完，奶盖塌陷后分层效果消失，口感大幅下降。

> **⚠️ 外卖慎点**：特调杯无杯盖，外卖途中橙皮会被闷成一团，香气损失严重，强烈建议自提。

### 甜度反直觉警告

博主提示：「少少甜」**并非** 最低糖度，「微微甜」才是。瑞幸糖度排序（参考品牌页）：

| 糖度 | 泵数 | 含糖量 |
| :--- | :--- | :--- |
| 不另外加糖 | 0 泵 | 0g |
| **微微甜**（最低） | 1 泵 | 5g |
| 微甜 | 2 泵 | 10g |
| 少少甜 | 3 泵 | 15g |

按直觉点单容易翻车「齁甜」。虎斑橘默认已是微微甜（最低），无需再加糖。

## 口感体验

**风味层次**（官方推荐「去盖直饮」体验）：

- 前调：焦糖味奶盖的甘甜与微焦香气
- 中段：黄油丝绒厚奶的醇厚奶香
- 主体：耶加雪菲的柑橘调性与咖啡苦韵
- 尾调：现刨橙皮碎即时挥发的清新橙香
- 余韵：清爽不酷烈，醇厚有骨架

**口感特点**：

- 虎纹分层视觉效果显著，开盖时冲击力强
- 黄油丝绒奶盖丝滑醇厚，无颗粒感
- 现刨橙皮碎提供油脂香气与咀嚼感
- 耶加雪菲柑橘调托起整杯骨架，避免过腻
- 微微甜（默认）糖度平衡，不抢咖啡与奶盖风头

**官方推荐喝法**：**无需吸管、不用搅拌，开盖直接饮用**——保留虎纹分层与顶部橙皮香气层次。

**最佳赏味期**：15 分钟内喝完，奶盖塌陷后分层效果消失。

**消费者评价关键词**：

- "像橘子奶油蛋糕"
- "柑橘调 + 咖啡 + 奶盖，经典结构"
- "开盖直饮体验感拉满"
- "微微甜刚刚好，多一分都齁"
- "无酒精版清爽，含酒精版微醺仪式感"

## 饮用建议

- **最佳杯型**：12oz 特调杯（**唯一可选杯型**）
- **最佳温度**：冰（**唯一可选温度**）
- **最佳糖度**：微微甜（**默认即最低糖度**，不建议再加）
- **最佳酒精**：无酒精（默认 / 性价比更优）
- **饮用方式**：去盖直饮，15 分钟内喝完
- **适宜场景**：下午茶尝鲜、社交打卡、低成本体验威士忌风味（+3 元入门）
- **不建议**：对乳制品过敏者（明确含乳）；追求浓郁咖啡味者（咖啡味在这杯偏弱）；当天需驾车者（务必无酒精版）
- **外卖提示**：特调杯无杯盖，橙皮会被闷成团，**强烈建议自提**
- **搭配推荐**：单喝即可，三层风味体验已足够丰富
