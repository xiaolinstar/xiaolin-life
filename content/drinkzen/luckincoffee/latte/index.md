## 制作方式调查

**官方主要原料**（✅ 来源：瑞幸官网 lkcoffee.com）：

- 浓缩咖啡（Espresso）
- 纯牛奶（可选全脂奶/脱脂奶）

**原料工艺**：

- 采用 IIAC 金奖咖啡豆，大师级定制 Espresso
- Espresso 与香醇牛奶精妙融合
- 入口明快柔和，后段坚果尾韵

**制作方式**（大杯 450ml）：

1. 浓缩咖啡液（Ristretto/Espresso）
2. 蒸奶/冰牛奶
3. 奶泡（热饮）

> **糖分说明**：
>
> - **总糖**（约 16.80g/杯）：包含乳糖和其他糖分
> - **乳糖**（约 16.80g/杯，豁免）：天然存在于牛奶中的糖分
> - **非乳糖糖**（约 0.10g/杯，计入分级）：来自咖啡的微量糖分
> - 选择「不另外加糖」可实现 **0 添加糖**，仅含牛奶乳糖
> - 脱脂奶版本 Nutri-Grade A 级（非乳糖糖 < 1g/100ml）
>
> **💡 为什么总糖 4g/100ml 还能评 A 级？**
>
> 新加坡 Nutri-Grade 标准**豁免乳糖**：
> - 分级计算：**含糖量 = 总糖 - 乳糖**
> - 拿铁总糖约 4g/100ml，其中乳糖约 4g/100ml
> - 非乳糖糖 = 4 - 4 = **约 0g/100ml** → A 级（< 1g/100ml）
> - 这与上海标准一致：乳糖不计入含糖量

**数据说明**：
1. 新加坡版为冰饮/脱脂奶版本，热量 149kcal；中国版为热饮版本，热量 268kcal
2. 糖分主要来自牛奶乳糖（豁免），非乳糖糖含量极低
3. 选择脱脂奶可大幅降低脂肪含量，Nutri-Grade 升级为 A 级

**Nutri-Grade 评级：A 级**（✅ 脱脂奶/不另外加糖）

- 非乳糖糖：约 0.02g/100ml（远低于 A 级标准 < 1g/100ml）
- 饱和脂肪：约 0.05g/100ml（脱脂奶版本极低）
- **关键**：选择「脱脂奶 + 不另外加糖」可实现 A 级评级

**新加坡 Nutri-Grade 分级标准**（豁免乳糖）：

| 等级 | 含糖量（不含乳糖） | 饱和脂肪 |
| :--- | :--- | :--- |
| A 级 | ≤ 1g/100ml | ≤ 0.7g/100ml |
| B 级 | 1-5g/100ml | 0.7-1.2g/100ml |
| C 级 | 5-10g/100ml | 1.2-2.8g/100ml |
| D 级 | > 10g/100ml | > 2.8g/100ml |

> **豁免说明**：新加坡标准计算含糖量时，**扣除乳糖和半乳糖**。拿铁总糖约 4g/100ml，但乳糖约 4g/100ml（豁免），非乳糖糖约 0g/100ml，所以可以评为 A 级。

## 饮用建议

- **最佳温度**：冰饮更清爽，热饮更醇厚
- **适宜场景**：早餐搭配、办公提神、日常休闲
- **不建议**：乳糖不耐受者慎选（可选生椰拿铁）
- **搭配推荐**：面包、三明治等早餐
- **控糖提示**：选择「不另外加糖 + 脱脂奶」可实现 0 添加糖 + 低脂
