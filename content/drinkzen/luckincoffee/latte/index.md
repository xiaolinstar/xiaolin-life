## 制作方式调查

**官方主要原料**（✅ 来源：瑞幸官网 lkcoffee.com）：

- 浓缩咖啡（Espresso）
- 纯牛奶（中国大陆仅提供全脂奶，可选燕麦奶）

**原料工艺**：

- 采用 IIAC 金奖咖啡豆，大师级定制 Espresso
- Espresso 与香醇牛奶精妙融合
- 入口明快柔和，后段坚果尾韵

**制作方式**（大杯 450ml，**按品牌页冰饮标准**）：

1. 浓缩咖啡液（Ristretto/Espresso）约 30ml
2. 冰全脂牛奶 约 **210ml**（冰标签线 / 液体基底标准线）
3. 冰块 约 **210ml**（冰至 400ml 线后加浓缩，再补满冰块）

> **数据校准**：品牌页明确「冰标签线 210ml = 液体基底」，210ml 牛奶 + 30ml 浓缩 + 210ml 冰 = 450ml。早期页面错误使用 330ml 牛奶 + 90ml 冰，已修正。

## 热饮估算（待实测）

**冰 vs 热关键差异**：冰拿铁因冰块占 210ml 体积，牛奶仅 210ml；热拿铁无冰块，**牛奶量应更多**（行业惯例倒满至杯线）。这会让 sat fat 浓度显著升高，可能从 B 级升至 C 级。

> **估算评级**：sat fat 2.15g/100ml（**进入 C 级区间 1.2-2.8g**）+ 非乳源糖 0.02g → **C 级**（饱和脂肪维度主导）

**与冰拿铁对比**：

| 规格 | 牛奶量 | sat fat/100ml | 评级 |

> **数据来源**：热饮牛奶量为行业惯例估算（液体倒满杯线），**待作者实测瑞幸热饮杯刻度确认**。
>
> **用户推测**：你提到"热拿铁或许是 C 级，因为牛奶和饱和脂肪含量高"——按行业估算的 420ml 牛奶数据，**C 级判断成立**。

## 饮用建议

- **最佳温度**：冰饮更清爽，热饮更醇厚
- **适宜场景**：早餐搭配、办公提神、日常休闲
- **不建议**：控糖要求极高者（可选燕麦奶替换，OATLY 燕麦奶 sat fat 约 0.2g/100ml 可能降至 A 级）
- **搭配推荐**：面包、三明治等早餐
- **控糖提示**：选择「不另外加糖」可实现 0 添加糖（仅含牛奶乳塘）
