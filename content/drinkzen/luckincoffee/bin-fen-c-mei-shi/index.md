## 产品速览

瑞幸咖啡 · 缤纷 C 美式 · 果咖（果汁 + 茶汤 + 美式）

- **系列**：果 C 美式系列（与升级版鲜果橙 C 美式同步上线）
- **Nutri-Grade 预估**：B 级 ⚠️（0 脂肪，糖分来自果汁天然糖）
- **热量**：约 100kcal（大杯 450ml / 冰 / 不另外加糖，官方口径「百大卡俱乐部」）
- **咖啡因**：约 37.1mg（官方口径，瑞斯奇托® 精萃咖啡基底）
- **价格**：9.9 元起，常规约 16.9 元
- **特点**：首次加入门店鲜切鲜橙片，叠加鲜切柠檬片 + 现捣小青桔，三重鲜果现制

## 制作方式调查

**官方主要原料**：

- 鲜切鲜橙片（当季夏橙，湖北秭归等产区，冷链到店门店现切）
- 鲜切柠檬片（四川安岳）
- 现捣新鲜小青桔
- HPP 缤纷果汁饮料（含凤梨、百香果、柠檬，超高压冷杀菌）
- 鲜萃现泡茉莉花茶汤（100% 真茶）
- 瑞斯奇托® 精萃咖啡（2025 IIAC 国际咖啡品鉴大赛金奖豆；超大杯替换为金奖豆 Espresso）
- 冰块

**原料工艺**：

- 鲜果不做浓缩还原：橙片、柠檬片门店现切，小青桔现捣出汁
- HPP（超高压冷杀菌）果汁保留更多风味与维 C，避免热杀菌的煮熟味
- 咖啡基底用瑞斯奇托®（Ristretto，短萃）而非常规 Espresso，出液更少、咖啡因更低（约 37.1mg）
- 因增加清洗、切配、捣制工序，上线初期部分门店出餐时长明显拉长

**制作方式**（大杯 450ml）：

1. 杯中放入鲜切鲜橙片、鲜切柠檬片
2. 加入现捣小青桔汁与桔肉，捣压出香
3. 注入 HPP 缤纷果汁饮料至标签线
4. 加入鲜萃茉莉花茶汤
5. 冰块补满
6. 最后注入瑞斯奇托® 精萃咖啡（超大杯为金奖豆 Espresso），形成分层

## 口感体验

**风味层次**：

- 前调：橙片与柠檬片的皮油香先冲出来，小青桔带来一记尖锐的青涩酸
- 中段：凤梨与百香果的热带甜酸铺开，茉莉花茶汤把果汁的稠甜削薄
- 尾调：瑞斯奇托® 的焦糖与坚果尾韵浮上来，微苦收尾，果香回落得慢

**消费者评价关键词**：

- 「鲜果现切，看得见果肉」
- 「比橙 C 美式更热闹，层次更多」
- 「咖啡因低，下午喝不影响睡觉」
- 「出餐太慢了，等了快 20 分钟」

## 饮用建议

- **最佳温度**：冰（果咖的鲜果香与分层都靠低温维持）
- **糖度推荐**：不另外加糖（HPP 果汁本身糖度已够）
- **适宜场景**：夏日午后、需要清爽提神但怕咖啡因过量、餐后解腻
- **搭配推荐**：与咸口三明治、贝果搭配；饮前摇匀让分层混合；不建议与含奶饮品同饮（果酸易致蛋白凝集）
