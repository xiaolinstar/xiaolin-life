饮品是日常里最容易被忽略的小事：随手买、随手喝、口味随机、热量未知。

奶茶仙人想做的事情很简单——**每天一杯，把数据记下来**。一杯饮品里有多少热量、多少糖、多少咖啡因、配料是什么，喝完有什么体感。这些数据在小程序里都有，每天打卡一次，把它们留在生活记录里。

这里的文章是推广运营的工作台：人设、内容、排期、拍摄规范都在这里持续更新。

## 测量说明

### Brix 与含糖量的区别

使用折光仪（测糖仪）测出的数值是 **Brix（°Bx）**，不是营养标签上的「含糖量」。

| 维度 | Brix（折光仪） | 含糖量（营养标签） |
| :--- | :--- | :--- |
| 测量对象 | 总可溶性固形物（糖 + 蛋白质 + 矿物质 + 有机酸等） | 仅碳水化合物中的糖分 |
| 脂肪干扰 | 有，脂肪影响折光率，导致读数偏高 | 无 |
| 典型差异 | 厚椰乳 10-17°Bx | 厚椰乳 3-5g/100ml |

**为什么高脂肪饮品 Brix 偏高？**

折光仪通过测量光在液体中的折射率来推算固形物含量。脂肪球会散射和折射光线，干扰读数。厚椰乳含脂肪约 6.5g/100ml（其中 80% 为饱和脂肪），导致 Brix 读数显著高于实际含糖量。

**示例：瑞幸生椰拿铁**

- 折光仪实测：约 11°Bx
- 实际含糖量：约 3-5%（厚椰乳天然糖分 + 牛奶乳糖）
- 差异原因：脂肪 + 蛋白质 + 咖啡有机酸等非糖固形物贡献了约 6-8°Bx

**结论**：Brix 读数仅供参考，不能直接等同于含糖量。如需精确糖分，应以营养标签或 HPLC 检测为准。
