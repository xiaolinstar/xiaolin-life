## 制作方式调查

**官方主要原料**（基于行业通用配方）：

- 浓缩咖啡（Manner 拼配豆）
- 过滤纯净水

**原料工艺**：

- 浓缩咖啡：使用 Manner 拼配豆制作的 Espresso，双份 60ml
- 水：Manner 净水机处理的过滤水

**制作方式**（大杯 355ml 冰）：

1. 杯中放入冰块（约占杯 1/3 体积）
2. 量取过滤水 235ml
3. 萃取双份浓缩咖啡（60ml）
4. 将浓缩咖啡倒入冰水中

**杯型及温度选项**（Manner 菜单 · 单选）：

| 冰度档位 | 说明 |
| :--- | :--- |
| 正常冰（推荐） | 标准冰量（约占杯 1/3，约 120ml） |
| 少冰 | 冰量减半 |
| 去冰 | 不放冰块 |

> **说明**：Manner 小程序标注"冰块可能部分融化，导致饮品不满杯"——冰饮实际液体量（不含冰块）小于去冰版。
>
> **热美式是独立菜单项**（"热美式 Hot Americano"），热量与液体量不同，详见 [热美式 Hot Americano](/drinkzen/manner/hot-americano/)（占位，待建）。

## 饮用建议

- **最佳温度**：冰饮 4-8°C
- **冰度推荐**：正常冰（推荐）/ 少冰 / 去冰
- **浓度推荐**：默认双份（推荐）/ 低浓度（单份，适合咖啡因敏感）/ 额外一份或两份（高强度提神）
- **适宜场景**：早晨提神、健身前后、工作专注时
- **不建议**：胃酸过多者空腹饮用
- **搭配推荐**：黑巧克力、坚果、全麦面包
- **控糖提示**：默认无糖无奶，是控糖最佳选择
