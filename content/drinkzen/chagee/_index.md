霸王茶姬（CHAGEE）2017 年创立于云南昆明，以"以东方茶，会世界友"为使命，主打"原叶鲜奶茶"系列。截至 2026 年 3 月，全球门店数达 7531 家，覆盖中国、马来西亚、美国等 9 个国家。2025 年 4 月在纳斯达克上市（股票代码：CHA），成为"新茶饮美股第一股"。

## 评级标准

霸王茶姬采用**上海「营养选择」标识**，由上海市疾病预防控制中心制定。

**评级规则**：根据非乳源性糖、饱和脂肪、反式脂肪、非糖甜味剂四项指标，取最低等级（短板原则）。

**伯牙绝弦示例**：

- 不另外加糖：B 级
- 标准糖：C 级

> 💡 评级体系详解见「[饮品健康评级：新加坡 ABCD 与中国上海标准](/drinkzen/nutri-grade/)」

## 糖度与点单建议

**糖度选项**（4 档）：

| 糖度 | 说明 |
| :--- | :--- |
| 不另外加糖 | 无额外糖浆，基底仍含天然糖 |
| 微糖 | 轻微甜度 |
| 少糖 | 中等甜度 |
| 标准糖 | 正常甜度 |

**官方数据查询**：

霸王茶姬小程序提供"热量计算器"，可实时查询不同配置（杯型/糖度/温度）下的：
- 热量、蛋白质、脂肪、碳水化合物
- 茶多酚、咖啡因
- 营养选择评级（A-D 级）
- GI 值（部分产品）

**糖度说明**：

霸王茶姬的糖度（标准糖/少糖/微糖/不另外加糖）是一个**相对概念**，不同饮品的添加糖量不同。经对比多款饮品热量数据发现：
- 同一糖度选项，不同饮品的添加糖量差异较大
- "标准糖"是相对于该饮品的"最佳口感"，而非统一克数
- 无法用统一公式换算糖度与具体糖量

> 💡 如需了解具体糖量，建议通过官方热量计算器查询，或对比不同糖度下的热量差异自行推算。

**大杯 vs 中杯**：

- 中杯容量约 450ml，大杯约 550ml
- 同等糖度下，大杯热量约为中杯的 1.2 倍
- 评级可能因杯型不同而变化（如中杯 B 级 → 大杯 C 级）

**评级标准差异**：

| 标准 | 糖分计算 | 不另外加糖的基底糖处理 |
| :--- | :--- | :--- |
| 上海"营养选择" | **非乳源性糖** | 乳糖豁免，其他天然糖计入 |
| 新加坡 Nutri-Grade | **总糖** | 全部计入（含乳糖） |

> 💡 若按新加坡标准（含乳糖），含乳饮品的糖量会更高，评级可能下降。

**温度对热量的影响**：

| 温度选项 | 热量差异 | 说明 |
| :--- | :--- | :--- |
| 标准冰 | 基准 | 冰块不增加热量 |
| 少冰 | 基准 | 冰量减少，容量不变 |
| 去冰 | +10-15kcal | 液体补足，略增热量 |
| 热饮 | +10-15kcal | 温度不影响主要营养成分 |

> 💡 热饮与冰饮热量差异仅 10-15kcal，可忽略。选择温度主要看口感偏好，不必过度纠结热量。

**杯型对热量的影响**：

- 大杯（550ml）≈ 中杯（450ml）× 1.3 倍
- 减脂期推荐中杯，既能解馋也更易控制热量

**减脂期推荐**：

- 橙柚康普（不另外加糖）：80kcal
- 青沫观音（不另外加糖）：101kcal
- 伯牙绝弦（不另外加糖）：130kcal
