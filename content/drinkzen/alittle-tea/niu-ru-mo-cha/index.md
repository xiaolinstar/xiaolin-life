## 配方与原料

**茶底**：抹茶粉

- 产地：日本或国产优质抹茶
- 风味特点：海苔香、鲜味浓郁
- 口感：细腻顺滑，微苦回甘

**基底配方**：

- 抹茶粉
- 鲜牛奶（非植脂末）

**牛乳特色**：

- 采用巴氏杀菌鲜牛奶
- 蛋白质含量更高
- 口感丝滑细腻
- 奶香自然浓郁

**健康承诺**：

- 0 香精
- 0 植脂末
- 现制现做

## 口感体验

**风味层次**：

- 前调：抹茶的清新海苔香
- 中段：鲜牛奶的丝滑奶香
- 尾调：茶奶交融的微苦回甘

**口感特点**：

- 抹茶的浓郁与鲜牛奶的丝滑完美结合
- 比普通抹茶奶茶更醇厚
- 口感细腻，层次丰富

**消费者评价关键词**：

- "浓郁丝滑"
- "抹茶控必点"
- "比想象中更好喝"

## 饮用建议

- **最佳温度**：冷饮更能体现抹茶清新，热饮浓郁醇厚
- **糖度推荐**：五分糖（抹茶有微苦，需要甜度平衡）
- **冰度推荐**：少冰或正常冰
- **适宜场景**：抹茶爱好者、下午茶、搭配日式甜点
- **不建议**：乳糖不耐受者、对咖啡因敏感者
- **搭配推荐**：可加红豆、芋圆增加层次

## 点单攻略

**经典搭配**：

- 牛乳抹茶 + 红豆 + 五分糖 + 少冰

**清爽搭配**：

- 牛乳抹茶 + 椰果 + 三分糖 + 正常冰

**隐藏菜单**：

- 牛乳抹茶 + 波霸 + 七分糖 + 去冰
