喜茶（HEYTEA）2012 年创立于广东江门，是新式茶饮品类的开创者和原创芝士茶的发明者。以"灵感之茶"为品牌理念，使用真茶、真奶、真果、真糖，坚持 0 奶粉、0 香精、0 奶精、0 氢化植物油。截至 2026 年 2 月，全球门店近 4000 家，覆盖 330+ 城市。

## 品牌简介

- **创立时间**：2012 年 5 月（广东江门）
- **总部**：深圳
- **创始人**：聂云宸
- **全球门店**：近 4000 家（截至 2026 年 2 月）
- **海外门店**：100+ 家，覆盖 8 个国家和地区
- **2025 年估值**：260 亿元（全球独角兽指数第 310 位）

**品牌定位**：新式茶饮开创者，原创芝士茶发明者

**品牌理念**：灵感之茶

**品质承诺**：

- 真茶、真奶、真果、真糖
- 0 奶粉
- 0 香精
- 0 高果糖玉米糖浆
- 0 奶精
- 0 氢化植物油
- 0 反式脂肪
- 0 速溶茶粉

## 产品系列

**芝士茶系列**（喜茶首创）：

- 原创芝士奶盖 + 真茶
- 代表产品：芝芝莓莓、芝芝芒芒、芝芝桃桃
- 开创了新式茶饮品类

**水果茶系列**：

- 真果肉 + 真茶
- 代表产品：多肉葡萄（经典爆款）、满杯红柚、满杯橙子
- 使用新鲜水果，非浓缩果汁

**抹茶系列**（千目抹茶）：

- 2025 年推出千目抹茶系列
- 代表产品：三倍厚抹、抹云椰蓝
- 全球推出 30+ 款含抹茶产品

**茶特调系列**（2025 年新品）：

- 以茶为主角的创新品类
- 代表产品：奇兰苹果杏（2025 年度"断货王"）
- 引领行业"特调"新方向

**波波奶茶系列**：

- 黑糖波波 + 鲜奶
- 代表产品：黑糖波波、奥利奥波波
- 每日现煮黑糖波波

**藏茶系列**（地域特色）：

- 藏区特色原料
- 代表产品：雪域牦牛乳恰安莫
- 将藏地风味带向全国

**纯茶系列**：

- 单一茶底，无添加
- 代表产品：纯绿妍、纯四季春
- 热量极低（0-20kcal）

## 糖度与点单建议

**糖度选项**（5 档）：

| 糖度 | 说明 |
| :--- | :--- |
| 0% | 无糖，不加任何糖浆 |
| 25% | 少糖 |
| 50% | 半糖 |
| 75% | 七分糖 |
| 100% | 标准糖/全糖 |

> ⚠️ 糖度为相对概念，表示标准糖的百分比。不同饮品的标准糖量不同，官方未公开具体克数。

**冰度选项**（4 档）：

| 冰度 | 说明 |
| :--- | :--- |
| 去冰 | 无冰块，风味更集中 |
| 少冰 | 冰量减少 |
| 正常冰 | 标准冰量 |
| 多冰 | 冰量增加，适合夏日 |

**杯型选项**：

| 杯型 | 容量 |
| :--- | :--- |
| 标准杯 | 约 500ml |
| 大杯 | 约 700ml |

**配料热量参考**：

| 配料 | 热量 | 糖量 |
| :--- | :--- | :--- |
| 芝士奶盖 | 80-120kcal | — |
| 波波（珍珠） | 90-130kcal | 18-25g |
| 椰果 | 30-50kcal | 5-8g |
| 抹茶冻 | 35kcal | — |
| 西柚果肉 | 10-20kcal | — |

> 💡 添加配料会显著增加热量和糖量。控糖建议：跳过芝士奶盖和波波，选择椰果或抹茶冻。

**减脂期推荐**：

- 纯茶系列（0-20kcal）
- 多肉葡萄（25% 糖版）
- 超级植物茶系列
- 跳过芝士奶盖和波波
