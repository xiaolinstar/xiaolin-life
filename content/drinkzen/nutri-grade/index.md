## 为什么需要健康评级？

一杯奶茶的含糖量可能超过每日推荐摄入量，长期过量摄入糖分会增加肥胖、糖尿病、心血管疾病等风险。为了帮助消费者识别饮品的健康程度，多个国家和地区推出了饮品健康评级体系。

目前最具影响力的两大体系是：

- 🇸🇬 **新加坡 Nutri-Grade**：全球首个强制实施的饮品分级制度
- 🇨🇳 **中国上海「营养选择」**：中国首个试点推行的饮品分级标识

## 两大体系一览

| 维度 | 新加坡 Nutri-Grade | 上海「营养选择」 |
| :--- | :--- | :--- |
| 实施时间 | 2022 年 12 月 30 日（预包装），2024 年 6 月 30 日（现场制售） | 2024 年起试点 |
| 适用范围 | 预包装饮料 + 现场制售饮品（奶茶、咖啡等） | 现制饮料（上海试点） |
| 实施性质 | **强制** | **自愿**（试点阶段） |
| 评级等级 | A、B、C、D | A、B、C、D |
| 糖 | 游离糖（豁免乳糖、半乳糖、整颗水果内在糖） | 非乳源性糖（豁免乳糖，不排除整颗水果内在糖） |
| 饱和脂肪 | ✅ 评估 | ✅ 评估 |
| 反式脂肪 | ❌ 不评估 | ✅ 评估 |
| 非糖甜味剂 | 使用不能获得 A 级 | 使用不能获得 A 级 |
| 评级原则 | 三项指标取最低等级 | 四项指标取最低等级 |
| 制定机构 | 新加坡卫生部（MOH）/ 保健促进局（HPB） | 上海市疾病预防控制中心 |

## 评级等级详解

两大体系的评级等级名称相同（A-D），但评判标准不同。

### 新加坡 Nutri-Grade 等级

评级标准根据游离糖和饱和脂肪含量（均以 g/100ml 计），**取最低等级**确定最终等级：

| 等级 | 游离糖（/100ml） | 饱和脂肪（/100ml） | 反式脂肪（/100ml） | 非糖甜味剂 | 备注 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| A 级 | ≤1g | ≤0.7g | — | 不使用 | 🟢 推荐 |
| B 级 | ≤5g | ≤1.2g | — | — | 🟡 较推荐 |
| C 级 | ≤10g | ≤2.8g | — | — | 🟠 少喝 |
| D 级 | >10g | >2.8g | — | — | 🔴 不推荐 |

> **糖的豁免**：游离糖不含牛奶中天然存在的乳糖（lactose）和半乳糖（galactose），也不含整颗水果/蔬菜中的内在糖（intrinsic sugars）。
> **甜味剂**：使用非糖甜味剂的饮品不能评为 A 级。

### 上海「营养选择」等级

采用**短板原则**，取四项指标中最低等级：

| 等级 | 非乳源性糖（/100ml） | 饱和脂肪（/100ml） | 反式脂肪（/100ml） | 非糖甜味剂 | 备注 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| A 级 | ≤0.5g | ≤0.75g | ≤0.3g | 不使用 | 🟢 推荐 |
| B 级 | ≤5g | ≤1.2g | ≤0.3g | — | 🟡 较推荐 |
| C 级 | ≤11.25g | ≤2.8g | ≤0.3g | — | 🟠 少喝 |
| D 级 | >11.25g | >2.8g | >0.3g | — | 🔴 不推荐 |

> **糖的豁免**：非乳源性糖排除了牛奶中天然存在的乳糖，但不排除整颗水果中的内在糖。
> **甜味剂**：使用非糖甜味剂的饮品不能评为 A 级。

## 两大体系核心差异

虽然等级名称相同（A-D），但两个体系存在以下关键差异：

### 1. 糖的定义与豁免

- **新加坡**：游离糖（Free Sugars），豁免牛奶中的乳糖和半乳糖，也豁免整颗水果/蔬菜中的天然糖分
- **上海**：非乳源性糖，仅豁免牛奶中的乳糖，**不排除**整颗水果中的天然糖分

| 糖的类型 | 游离糖（新加坡） | 非乳源性糖（上海） |
| :--- | :--- | :--- |
| 添加糖 | ✅ 计入 | ✅ 计入 |
| 蜂蜜/糖浆中的糖 | ✅ 计入 | ✅ 计入 |
| 果汁中的糖 | ✅ 计入 | ✅ 计入 |
| 整颗水果中的天然糖 | ❌ 不计入 | ✅ 计入 |
| 牛奶中的乳糖 | ❌ 不计入 | ❌ 不计入 |

> **实际影响**：纯水果昔（不加糖）在新加坡可能为 A 级（游离糖为 0），但在上海可能因水果中的天然糖而降至 B/C 级。

### 2. 甜味剂处理

两个体系规则一致：使用非糖甜味剂的饮品不能评为 A 级。

### 3. 脂肪指标

- **新加坡**：只评估饱和脂肪
- **上海**：同时评估饱和脂肪和反式脂肪

### 4. 评级原则

两个体系均取**最低等级**作为最终评级，区别在于评估指标数量：

- **新加坡**：3 项指标（游离糖、饱和脂肪、非糖甜味剂）取最低等级
- **上海**：4 项指标（非乳源性糖、饱和脂肪、反式脂肪、非糖甜味剂）取最低等级

### 5. 行业影响

新加坡实施后，奶茶店纷纷推出低糖选项；上海试点以来，参与品牌主动优化配方以争取更高等级。

## 实际应用指南

### 点单时如何参考？

| 场景 | 推荐等级 | 说明 |
| :--- | :--- | :--- |
| 日常解渴 | A 级 | 纯茶、黑咖啡、气泡水 |
| 偶尔犒赏 | B 级 | 低糖拿铁、少糖果茶 |
| 控制频率 | C 级 | 标准糖奶茶、调味咖啡 |
| 尽量少喝 | D 级 | 全糖特调 |

### 常见饮品等级参考

| 饮品类型 | 新加坡等级 | 上海等级 | 说明 |
| :--- | :--- | :--- | :--- |
| 纯茶（无糖） | A 级 | A 级 | 最健康选择 |
| 美式咖啡 | A 级 | A 级 | 纯咖啡无糖无脂肪 |
| 拿铁（不另外加糖） | B 级 | A 级 | 饱和脂肪导致新加坡 B 级 |
| 脱脂奶拿铁 | A 级 | A 级 | 饱和脂肪低 |
| 少糖果茶 | B 级 | B 级 | 糖分降低 50% |
| 标准糖奶茶 | C/D 级 | C 级 | 含糖量高 |
| 全糖珍珠奶茶 | D 级 | D 级 | 含糖量和脂肪双高 |
| 含甜味剂饮品 | B/C/D 级 | B/C/D 级 | 两地均不能评为 A 级 |

> **注**：拿铁在新加坡为 B 级，是因为全脂奶的饱和脂肪（~1.8g/100ml）超过 B 级阈值（1.2g/100ml），而非糖含量——牛奶中的乳糖已被豁免。脱脂奶拿铁因饱和脂肪极低（~0.1g/100ml），可获得 A 级。

### 小料的含糖量

不同小料会显著影响饮品的最终等级：

| 小料 | 含糖量 | 等级影响 |
| :--- | :--- | :--- |
| 珍珠 | 高 | ⬆️⬆️⬆️ |
| 椰果 | 中 | ⬆️⬆️ |
| 芋圆 | 中高 | ⬆️⬆️ |
| 仙草 | 低 | ⬆️ |
| 布丁 | 中 | ⬆️⬆️ |
| 脆波波 | 中 | ⬆️⬆️ |
| 奶盖 | 高（脂肪 + 糖） | ⬆️⬆️⬆️ |

> **建议**：选择 A/B 级饮品时，尽量搭配低糖小料（仙草、蒟蒻），避免珍珠、奶盖等高糖高脂小料。

## 常见问题

### Q：为什么纯牛奶也只拿到 B 级？

**A**：牛奶中天然含有饱和脂肪（全脂奶约 1.8g/100ml），超过了 B 级的饱和脂肪阈值（1.2g/100ml）。脱脂奶因为饱和脂肪极低（~0.1g/100ml），可以获得 A 级。牛奶中的乳糖（天然糖分）在两个体系中均被豁免，不计入糖含量。

### Q：两个体系的评级会不一样吗？

**A**：会。由于评判标准不同，同一杯饮品在两个体系中可能获得不同等级。例如，不另外加糖的拿铁在新加坡是 B 级（饱和脂肪超标），在上海是 A 级（非乳源性糖为 0 且反式脂肪低）。一般来说，上海标准相对更宽松一些，但对甜味剂的管控更严格。

### Q：使用 0 卡糖会提升评级吗？

**A**：两个体系规则一致——使用非糖甜味剂的饮品不能评为 A 级。因此 0 卡糖虽然可以降低糖含量，但含有甜味剂本身就会限制最高评级为 B 级。

### Q：「不另外加糖」真的无糖吗？

**A**：不另外加糖 ≠ 无糖。饮品中可能含有配料自带的糖分（如水果中的果糖、珍珠中的糖分），只是没有额外添加糖浆。在新加坡体系中，这些配料中的糖仍计入游离糖。

### Q：评级越高就一定越好吗？

**A**：评级是基于糖和脂肪的综合评估，但不等于「健康」。A 级饮品可能含有咖啡因或其他成分，D 级饮品偶尔享用也无妨。评级只是帮助你做出更明智的选择，而非绝对的健康标准。
