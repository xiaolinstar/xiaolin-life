## 为什么需要饮品健康评级？

糖摄入过量是全球性的健康问题。世界卫生组织（WHO）建议每日糖摄入不超过 50 克，但一杯普通奶茶的含糖量就可能达到 40-60 克。

饮品健康评级的核心目的是：**让消费者在购买瞬间就能判断饮品的健康程度**，而不需要翻看复杂的营养成分表。

## 新加坡 Nutri-Grade：全球最严格的分级

### 新加坡背景

新加坡是全球糖尿病发病率最高的国家之一，人均每日糖摄入 60 克，其中超过一半来自饮料。

2022 年 12 月 30 日，新加坡正式实施 **Nutri-Grade 饮料营养分级制度**，成为全球首个强制要求饮品标注健康等级的国家。

### 新加坡分级标准

Nutri-Grade 根据每 100 毫升饮料中的**含糖量**和**饱和脂肪含量**，将饮品分为四个等级：

| 等级 | 颜色 | 含糖量（/100ml） | 饱和脂肪（/100ml） | 标注要求 |
| :--- | :--- | :--- | :--- | :--- |
| **A** | 深绿 | ≤ 1g，且不含甜味剂 | ≤ 0.7g | 自愿标注 |
| **B** | 浅绿 | 1-5g | 0.7-1.2g | 自愿标注 |
| **C** | 黄色 | 5-10g | 1.2-2.8g | **强制标注** |
| **D** | 红色 | > 10g | > 2.8g | **强制标注 + 禁止广告** |

### 关键规则

1. **木桶效应**：最终等级取决于糖和饱和脂肪中**较差**的那个。
2. **甜味剂限制**：使用人工甜味剂的饮品，即使无糖，也只能评为 B 级。
3. **覆盖范围**：预包装饮料、冲泡饮料、自动售货机饮品、**现制饮品**（珍珠奶茶、现磨咖啡等）。
4. **广告禁令**：D 级饮品禁止在所有媒体平台投放广告。

### 实施效果

- 预包装饮料中位糖含量从 2017 年的 7.1% 降至 2021 年的 4.6%
- A/B 级饮品市场份额从 37% 升至 71%
- 多个品牌主动改良配方以获得更好等级

## 中国上海「营养选择」：国内首个分级试点

### 上海背景

2024 年 4 月，上海市卫生健康委员会启动「首批营养健康指导试点项目」，推出中国首个饮料「营养选择」分级标识。这是我国首次在饮品领域引入正面包装标识（FOP）制度。

首批试点企业包括：**霸王茶姬、奈雪的茶、快乐柠檬、杭州乐源**。

### 上海分级标准

「营养选择」根据每 100 毫升饮料中的**四项指标**进行综合分级：

| 等级 | 颜色 | 非乳源性糖 | 饱和脂肪 | 反式脂肪 | 非糖甜味剂 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **A** | 深绿 | ≤ 0.5g | ≤ 0.75g | ≤ 0.3g | 不使用 |
| **B** | 浅绿 | 0.5-5g | 0.75-2.5g | ≤ 0.3g | 可使用 |
| **C** | 黄色 | 5-11.5g | 0.75-2.5g | > 0.3g | 可使用 |
| **D** | 红色 | ≥ 11.5g | ≥ 2.5g | > 0.3g | 可使用 |

### 上海关键规则

1. **木桶效应**：最终等级取决于四项指标中**最差**的那个。
2. **非乳源性糖**：排除牛奶中的乳糖，避免「误伤」牛奶。
3. **甜味剂限制**：使用非糖甜味剂的饮品不能评为 A 级（一票否决）。
4. **界限值来源**：
   - 0.5g/100ml：国标「无糖」界限
   - 5g/100ml：国标「低糖」界限
   - 11.5g/100ml：《中国居民膳食指南》「高糖」界限

### 试点进展

- A/B 类饮品销量有较大增幅
- 消费者在点单页面可直观看到分级标识
- 企业开始调整配方以获得更好等级

## 两大体系深度对比

| 维度 | 新加坡 Nutri-Grade | 上海「营养选择」 |
| :--- | :--- | :--- |
| **实施时间** | 2022 年 12 月 | 2024 年 4 月（试点） |
| **性质** | 全国强制 | 城市试点（自愿参与） |
| **评估指标** | 糖 + 饱和脂肪 | 糖 + 饱和脂肪 + 反式脂肪 + 甜味剂 |
| **A 级糖含量** | ≤ 1g/100ml | ≤ 0.5g/100ml |
| **甜味剂处理** | 含甜味剂 → B 级 | 含甜味剂 → 不能 A 级 |
| **乳糖处理** | 不区分 | 排除乳糖（非乳源性糖） |
| **广告限制** | D 级禁止广告 | 无 |
| **覆盖范围** | 全品类饮品 | 试点企业产品 |
| **标注要求** | C/D 强制标注 | 自愿标注 |

### 核心差异

1. **上海更严格**：A 级糖含量要求（≤ 0.5g）比新加坡（≤ 1g）更严格。
2. **上海更全面**：增加了反式脂肪和甜味剂两项指标。
3. **新加坡更强制**：全国强制执行，D 级禁止广告。
4. **上海更友好**：排除乳糖，不「误伤」牛奶。

## 实际案例对比

以常见饮品为例，看看两个体系的评级差异：

| 饮品 | 新加坡 Nutri-Grade | 上海「营养选择」 | 说明 |
| :--- | :--- | :--- | :--- |
| 美式咖啡（无糖） | A | A | 两个体系一致 |
| 拿铁（全脂牛奶） | B-C | B-C | 饱和脂肪导致降级 |
| 珍珠奶茶（正常糖） | D | D | 高糖高脂 |
| 零度可乐 | B | B | 含甜味剂，无法 A 级 |
| 鲜榨橙汁 | C-D | C-D | 天然糖分高 |
| 全脂纯牛奶 | B-C | A-B | 上海排除乳糖，更友好 |

## 奶茶仙人的评级标准：基于新加坡 Nutri-Grade

奶茶仙人采用**新加坡 Nutri-Grade**作为饮品评级标准，原因如下：

1. **全国强制执行**：经过市场验证，数据可靠
2. **覆盖现制饮品**：包含珍珠奶茶、现磨咖啡等奶茶仙人关注的品类
3. **指标简洁明确**：糖 + 饱和脂肪，易于理解和计算
4. **广告限制机制**：D 级禁止广告，倒逼行业改良

### 评级对照表

| 等级 | 含糖量（/100ml） | 饱和脂肪（/100ml） | 奶茶仙人建议 |
| :--- | :--- | :--- | :--- |
| **A** | ≤ 1g，不含甜味剂 | ≤ 0.7g | ✅ 优先选择 |
| **B** | 1-5g | 0.7-1.2g | ✅ 日常饮用 |
| **C** | 5-10g | 1.2-2.8g | ⚠️ 限量饮用 |
| **D** | > 10g | > 2.8g | ❌ 尽量避免 |

### 常见饮品参考

| 饮品类型 | 预估等级 | 说明 |
| :--- | :--- | :--- |
| 美式咖啡（无糖） | A | 纯咖啡，无糖无脂 |
| 纯茶（无糖） | A | 茶水，无糖无脂 |
| 拿铁（正常糖） | C-D | 牛奶饱和脂肪 + 糖分 |
| 珍珠奶茶（正常糖） | D | 高糖 + 高饱和脂肪 |
| 零卡饮料 | B | 含甜味剂，无法 A 级 |
| 鲜榨果汁 | C-D | 天然糖分高 |

**记住**：评级只是参考，关键在于**总量控制**。一天一杯 A 级饮品，比一周一杯 D 级更健康。
