## 制作方式调查

门店制作流程（品牌内部饮品配方培训材料口径，2024-07 公开考核题）：

1. 杯中先加**全脂牛奶**
2. 注入**浓缩咖啡液 1 份**
3. 继续加奶至**冰杯三线处**
4. 最后加冰至**冰杯出餐标准处**

> 该材料把奶咖做法分为「经典拿铁派」（先奶 → 浓缩 → 加奶至冰杯三线 → 最后加冰至出餐标准处）与「现代拿铁派」（先奶 → 加冰至杯口 → 最后加入咖啡液），**拿铁走经典派**。
>
> 冰杯刻度（三线 / 出餐标准处）对应的毫升数未公开，门店实际冰量、奶量、浓缩份量与奶泡用量仍无公开数值；本页按「牛乳 / 浓缩咖啡液 / 冰块」配比估算（见下节），置信度中。

### 热量

| **本站配料推导（主口径）** | 139 kcal | **201 kcal** | 牛乳 / 浓缩咖啡液 / 冰块逐项相乘后汇总 |
| 官方公布值（对照） | 163 kcal | 未公开 | 训练指引手册标准出品（中杯、标准冰），实验室测定及估算，2024-06 |

> **计算模型**：原料用量 × 每 100ml 营养值 = 该原料贡献 → 各原料相加 = 每杯总值 → 每杯总值 ÷ 有效体积 × 100 = 每 100ml 浓度。**不使用官方热量反推原料用量**。
>
> **与官方值的差异**：中杯配料推导 139 kcal vs 官方 163 kcal，差 15%。可能来源：① 冰量按官方商品图目测 ≈1/4 杯容，实际可能更少（若奶量提高到约 259ml、冰降到约 46ml，推算正好回到 163 kcal）；② 品牌「牛乳」能量密度高于国标全脂标签值 62 kcal/100ml；③ 「覆以微量奶泡」若由额外乳脂打发，本页未计入。**差异不影响评级结论**（见评级稳健性）。
>
> 另有第三方测评（2023-08）给出中杯拿铁 120 kcal，该测评未注明冰量、奶量与奶泡口径，与官方 2024-06 数据无法直接对齐，**并列记录不作为推算依据**。

### 评级稳健性

- 配料推算与官方值两套口径下评级完全一致：官方值反推的配方（奶 ≈259ml / 冰 ≈46ml）饱和脂肪 1.75g/100ml，本页配料推算 1.53g/100ml，同属新加坡 C（>1.2 且 ≤2.8）、上海 B（>0.75 且 ≤2.5）
- 新加坡 C 级成立的前提是奶量充足：大杯 ≥250ml、中杯 ≥177ml（饱和脂肪 ≥1.20g/100ml）。若实际冰量超过约杯容 38%，中杯饱和脂肪会跌破 1.2g/100ml，新加坡降为 B 级
- 热饮与去冰（无冰、奶补满）大杯饱和脂肪升至 2.12g/100ml，仍低于上海 B 级上限 2.5 与新加坡 C 级上限 2.8
